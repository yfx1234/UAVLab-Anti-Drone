# 当前环境与参考资料

当前实机为 NX16GB，现行环境见 `current-nx16.json` 与 [修复记录](../docs/NX修复与优化_2026-10-13.md)；`hardware/nx16/README.md` 记录启动适配、备份与回退。下列 Nano 内容是迁移前的历史基线。

current-nano.json 是经固定图传SSH只读采集的现机版本清单，含实际PT/ONNX/引擎哈希与56个板上源码一致性检查。采集不改变相机状态。

环境清单采集时对应部署代码76cea9f；此后仓库为迁移准备增加了文档、可携带启动/部署工具、输出目录环境变量与默认关闭历史工具的构建选项。这些新仓库工具不代表已在NX部署。

硬件启动配置放在hardware，仅供当前Nano参考。当前Nano运行程序不因仓库上传而重启。原驱动记录的深度PERFORMANCE测试发生在2026-10-07，现用感知深度为NEURAL_LIGHT。

SDK/驱动/模型张量是否可用要分别检查，不能仅依赖dpkg包列表；NX环境到位后另存nx实测清单，不覆盖Nano基线。

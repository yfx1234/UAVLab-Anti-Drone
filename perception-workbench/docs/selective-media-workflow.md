# 视频分类下载：代码流程、修改与实测（2026-10-11）

这轮仍针对当前Nano8GB。电脑负责播放、整理、抽帧、标注和训练；ZED专有SVO解码和深度重算由板子在释放相机后完成。没有安装Windows ZED SDK，没有更改驱动、网络、功耗或旧飞控入口。

## 最终代码流程

1. 唯一zed_perception_standalone采集1920×1080双目图像。默认15fps；配置仅允许15/30。原始SVO、逐帧时间戳、识别元数据和场次信息在板上保存。JPEG预览和原始录像共用采集，电脑不再另开ZED相机。
2. 原始录像停止后先关闭分段、排空元数据，再标记收尾。视频生成时按分段帧数和时间戳SHA256校验；历史缺少可靠收尾标志的场次不会假装合格。
3. PC的download_asset查询板上只读ready_media：有与源文件/完整验证记录绑定的已生成视频，直接下载；没有时先要求相机停止，再调用export_session。
4. export_svo_rgb直接从SVO读取原生1920×1080图像并编码MP4，不先导出一大堆PNG。RGB不加识别框；深度仅在请求时使用NEURAL_LIGHT重算并输出彩色展示。原始SVO没有被修改。
5. 视频时间轴按真实时间戳维持时长，空隙重复前帧。报告区分unique_capture_hz、repeated_video_frames与video_fps，防止把重复帧当新采集帧。临时MP4经过完整解码、分辨率和帧数检查后才发布。
6. SessionManager只下载选中的RGB/depth/SVO，不自动带上其余类型、日志或标定文件。SFTP读取每批最多512KiB，按约1秒检查采集状态；采集中256KiB/s，可靠停止后不限速，状态不明回到限速。
7. 本机.part支持续传；源文件前后SHA256与本机SHA256一致才发布。拒绝越界/符号链接，电脑保留1GiB余量，板上导出保留10GiB。
8. MediaLibrary在电脑保留下载MP4，再做同尺寸/同时间轴H264浏览器播放副本。HTTP Range支持拖动；抽帧也在电脑进行，产生PNG待人工标注。
9. 下载过程中保留停止相机/板上录像/本机录像操作；传输或PC播放转换阶段可以重新启动相机并自动降速。板上转换阶段不开放启动。服务重启更换instance_id；网页提示刷新，任务404/认证403结束等待，不自动重发旧命令。

## 页面保留内容

连接、相机模式、采集帧率、YOLO启停、板上原始录像、本机预览录像、RGB/YOLO预览、相机坐标、分类下载、本机视频播放与训练图片抽取。移除了模型测试、标定、诊断及板上导出等工程操作入口，相关SSH工具仍保留。

## 分辨率、帧率、传输结果

- 当前旧引擎输入1280×736，相机/下载1920×1080。1920输入需要重新导出TensorRT引擎及适配合同校验；常见stride32输入应为1920×1088，像素工作量比为2.21739。此比例不是已测推理耗时或显存倍数。NX16GB并不自动保证30fps。
- 30fps、纯RGB、YOLO关闭、无损SVO试录：595帧，32.632199秒，独立图像18.20288Hz，时间间隔中位数66.643ms，最大133.346ms。短测30fps不合格，保留15fps默认。
- 同一片段视频输出1920×1080、30fps、980播放帧、32.6667秒；包含重复帧。RGB25,585,638字节，深度展示3,864,978字节，原始双目全场约1.7GiB。板上SVO回放/元数据时间戳一致、595帧完整。
- 停止相机的SFTP实测8MiB，稳态699,936B/s≈0.6675MiB/s≈5.60Mbps，无软件限速；该结果只代表当时H100/SSH通道，不足以单独定位无线链路、往返时延或SSH的瓶颈。1GiB按此速度约25.6分钟。正常RGB下载只传24.4MiB，避免误把整场SVO一起传。
- 真实网页已完成采集中下载缓存RGB、下载时停止相机并切换高速、RGB和深度完整下载和浏览器播放、本机抽取65张PNG。两种视频浏览器读出1920×1080、32.6667秒。

## 验证与边界

本机24项回归：23通过、1项Windows符号链接权限跳过；额外面板2项通过。新增测试覆盖分类筛选、缓存源变更失效、缓存绕过相机导出、传输状态切换、取消续传及哈希、空间不足、浏览器播放副本。板上构建通过，67项测试0错误0失败；显式部署的5个板上文件已逐字节核对。

一次完整代码审查发现3个重要问题，已一轮修复：缓存下载被离线限制挡住、长任务挡住停止控制、服务重启任务404无限等待/旧令牌403。原审查记录与修复证据分开保留；未安排第二轮复审。

当前没有真实四旋翼精度验收、30分钟/2小时压力验收、NX30fps验收或1920推理实测。首次板上转换不能立即取消，取消在转换结束后生效；下载与本机播放副本可中止。深度展示重算结果不等于当时在线算法逐像素输出，SDK/模型版本可能影响重算。

## 主要改动文件

board/zed_tracking/src/zed_perception_standalone.cpp：采集15/30配置。
board/zed_tracking/tools/export_svo_rgb.cpp：原生视频流式导出、可选深度、时间轴及独立帧统计。
board/zed_tracking/tools/export_session.py：验证和缓存。
board/zed_tracking/tools/perception_supervisor.py：参数白名单和只读缓存查询。
panel/session_manager.py：分类、批量读取、动态限速、续传和校验。
panel/media_library.py：PC播放副本、抽帧和素材登记。
panel/dashboard.py、panel/index.html：下载编排、HTTP视频、日常操作界面和重连恢复。

# 数据集深度参考标定检查

目标：判断同一目标机的历史数据能否支持自训检测框的尺寸测距标定，给出有证据的结果与适用范围。

边界：仅感知与离线评估，不读取专项模块；不以彩色MP4反推深度；不以旧尺寸先验过滤后的距离作为独立真值；不把双目参考标为外部测量真值。相机未录像时已获准停止。

- [x] 核查五场数据元信息、相机内参、模型绑定和原始SVO保留情况；确认同一目标机。
- [x] 按SVO原始时间戳匹配记录框，独立重算米制深度与置信度，保存可核查缩略图。
- [x] 检查误检/背景、样本覆盖、时间相关性以及分场次误差；足够时拟合候选，证据不足时明确不应用。
- [x] 输出结果与可重复分析工具，验证、提交并同步GitHub/Gitee，更新知识库。

用户追加约束：人物场次c9c6整场、b996第4段position≥410（截图28–33与后续建筑背景）从标定中排除，不删除素材。

结果：原始1374次grab、1031帧匹配、1100条框样本；当前NX默认模型在74个纯天空帧重测，43个有效1秒块。候选0.246954m，留整场验证中位相对误差7.65%/8.44%，参考2.657–9.606m。无外部距离真值与10m以上验证，候选明确未应用实时参数。

验证：5项Python测试由缺失实现/排除参数失败到通过；Jetson原生构建与真实米制深度+当前引擎抽样、错误引擎绑定、深度质量/投影测试通过；新增现场相机保护，运行时拒绝离线回放且不创建输出。恢复原RGB/HD1080/15、自训1280×736和0.55，录像idle。最终板上工具源码与仓库哈希一致。

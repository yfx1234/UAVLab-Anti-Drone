# 天空通用检测规格

用户授权实现免训练的天空目标检测，并准备第二天实物测试。相机随载机/云台运动，背景主要为天空/云，目标通常约30cm、2–30m、多数20m内。当前采集仍用Nano，后续才迁移NX。

- 使用板上原图发现明暗局部目标，采用多尺度；候选不依赖YOLO，不要求固定四旋翼形状。
- 通用检测独立启停，可与YOLO同时运行；始终共用唯一相机、深度和SVO。RGB仍为启动默认。
- 连续帧确认，使用图像时刻IMU姿态和工厂IMU到相机旋转补偿相机转动；缺失/过期IMU明确降级，不伪造补偿。悬停目标也能被发现。
- 输出通用候选评分、来源和未知类别；通用评分不视为类别概率。联合运行同一目标不重复显示，保存各方法结果供复盘。
- 保留有质量支持的深度位置；无深度时按明确约30cm先验估轴向Z，再解算相机XYZ。通用候选不继承YOLO框标定。小框、触边只给方向，坐标协方差仍标无效。
- SDK12m上限和现有10.5m深度质量门限保持；20–30m允许尺寸估距，不能把估距标为测得深度。
- 不自动录制，不上飞控，不更改驱动/网络/时区；默认1080p/15fps，算法CPU/内存必须有界。
- 前端增加通用启停和三档灵敏度，检测叠加同时支持YOLO/通用；目标表高度、素材功能保留，页面不加工程说明段落。
- 实物精度/漏检/误报明天再验收；今晚完成合成输入、无目标室内实机、模式切换/SVO完整性、界面与GitHub同步验证。

# 单目软靶直接接触模式

## 〇、递增冲刺版（2026-09-09）

本版本面向 0-2 m/s 慢速移动的气球类软靶，把三段接近速度从递减（1.0/0.5/0.3 m/s）改为递增冲刺（1.5/2.2/3.5 m/s）：远段对准、末段加速、接触窗口以最高速度完成撞击，保证对 2 m/s 靶标的尾部追击仍有 1.5 m/s 相对闭合速度。针对伺服链『追在目标后面』的教训，新增有界线性提前量瞄准（lead pursuit）：由角速率与距离变化率估计目标线速度，把瞄准点沿目标运动方向前移，提前量以米为单位限幅。配套变更有：接触窗口超时 4.0s 收紧到 1.5s、制动保持 0.35s 加长到 0.6s、接触骤降判据改为对窗口内峰值速度比较。2026-09-10 修订（外场审查 9 项全部核实的修复）：目标速度估计扣除本机运动、径向速度不再挤占限幅额度、提前量时间改用限幅后的实际指令速度、接触丢失按“持续未见目标”的时长判定、总水平/垂直限幅默认上调至 4.5/3.5 并开放启动参数、制动与退避增加停稳校验、阶段支持带滞回的降级。感知、锁定与上游安全门保持不变。2026-09-10 追加修订（提前量几何一致性）：目标速度限幅缩放整条速度向量时径向分量同步缩放，闭合速度计算不再使用缩放前的径向值；接触时间改按“指令速度在瞄准方向上的投影”定点迭代求解——瞄准点前移后一部分速度转为侧向，真正缩短距离的径向分量随提前角余弦缩减，不修正会系统性少瞄约 10-15%（典型场景 0.80s → 0.917s）。2026-09-11 修订（解除高度门控）：气球靶为 1-2 米低空目标，飞手须在 3 米以下悬停就位，3 米高度下限曾让整场任务停在 LOCKING；高度不再作为任务门控，minimum_height_m 降为 0.5 米仅作贴地保护（低于该高度接近/退避指令不再下降），maximum_height_m 保留参数兼容但不再强制。2026-09-11 第二次修订（Offboard 门控与断流保持）：新增订阅 /fmu/out/vehicle_status，未进入 Offboard 时状态机停在 LOCKING（锁定照常建立），不在地面与手动就位阶段提前消耗任务；接近/末段的数据断流不再直接中止，改为 HOLD 状态零速度等待重捕获（默认 3 秒，measurement_hold_timeout_s），目标恢复且重新锁定后回到原阶段，超时才中止。飞手中途退出 Offboard 即视为接管，任务进入中止，需 flight.sh next 重新开始。

## 一、用途与边界

本软件包用于封闭试验场内，让无人拦截器依靠顶部单搜索相机，对无人、轻质、可变形的试验靶完成一次低速直接接触；确认接触后立即制动、沿来向小幅退离并悬停。它不适用于人员、有人飞行器、车辆、建筑、硬质目标、带危险载荷目标或场外飞行。

这是一个全新的独立软件包 `falcon_contact`。原有 `falcon_intercept` 的单搜索、双目、伺服、安全适配和相机代码均未修改。新启动文件只复用原有检测、角度转换、上游隔离和飞控安全适配节点。

节点绝不发送解锁、上锁或飞行模式切换命令，也不会在空中主动停桨。接触后的动作是“制动—低速退离—悬停”，飞手始终保留退出外部控制模式的最高优先权。

## 二、运行原理

数据链路如下：

搜索相机图像 → 检测结果 → 搜索角度 → 同帧配对 → 稳定锁定 → 延迟补偿与运动预测 → 沿预测视线接近 → 接触判定 → 制动 → 退离 → 悬停

关键处理如下：

1. **同帧配对**：检测框和角度消息必须具有相同帧序号，并再次核对采集时间。不同帧的数据不会混用。
2. **采集时刻姿态补偿**：节点保存最近两秒的机体姿态，在图像采集时刻进行插值，用该时刻姿态把相机视线变换到北东地坐标系，避免拿当前姿态解释旧图像。
3. **稳定锁定**：至少连续八帧满足置信度、帧间隔、角度跳变和检测框尺度变化限制，才允许开始接近。目标跳变或数据断流会重新锁定或中止。
4. **延迟预测**：预测时间由“图像实际年龄 + 控制响应余量 + 末段小幅引导提前量”组成，默认最多零点四五秒；角速度和最大预测偏角也分别限幅。预测达到上限时继续限幅，不会无限外推。在此基础上叠加**有界线性提前量**：由角速率与视尺寸距离变化率估计目标线速度（限幅默认 2.5 米每秒），按剩余接近时间把瞄准点沿目标横向速度前移（前移距离限幅默认 1.0 米，死区 0.25 米每秒）。角度假提前量在近场会失效（近距离小角度对应大线位移），以米限幅的提前量正是为此设计；静止或极慢目标自动退化为原视线瞄准。2026-09-10 起目标速度估计扣除本机运动：横向按“相对角速度×距离 + 本机横向速度”合成，径向按“膨胀率×距离 + 本机径向速度”单独估计；2.5 米每秒限幅只作用于目标自身速度估计，本机关闭速度不再挤占横向提前量额度（否则高速接近时横向提前量会被压掉三成以上）。同期几何一致性修订：限幅缩放速度向量时径向分量同步缩放；接触时间按指令速度在瞄准方向上的投影（随提前角余弦缩减）定点迭代求解，消除提前转向带来的系统性少瞄。
5. **单目接近量**：距离由检测框相对图像尺寸估算；检测框对数尺度的增长率用于估算剩余接近时间。两者共同决定远段、末段和接触窗口，避免只相信抖动较大的单目距离。
6. **直接接近（递增冲刺轮廓）**：控制量是沿预测拦截点方向（预测视线叠加线性提前量）的北东地速度。远段、末段、接触窗口默认速度依次为每秒一点五米、二点二米、三点五米，逐级递增，撞击瞬间速度最高；对 2 米每秒靶标的尾部追击闭合速度约 1.5 米每秒。阶段支持带滞回的降级：更低阶段的条件持续 0.5 秒才退回，防止单次距离或检测框抖动把状态永久顶在高速度段。飞控的位置速度控制器负责形成相应倾角，因此飞行方向会跟随预测视线，而不是继续保持固定间距追在目标后方。
7. **接触确认**：只有先进入近距离接触窗口，出现“持续未见目标”（同帧配对超过 0.20 秒未更新、再持续 0.08 秒确认），或同时出现加速度突变与相对窗口内峰值速度的下降，才确认接触。丢失时长从目标真正消失时起算，而不是进入窗口时刻；高速下确认前的盲冲距离由约 1.4 米收窄到约 0.7 米。冲刺轮廓下窗口内仍在加速，骤降判据对窗口内峰值速度比较，擦碰减速到高于进入速度时同样能识别。单独一次检测丢失不会在远距离被当成接触。
8. **一次结束**：接触确认后制动（最短 0.6 秒且实际速度降到 0.4 米每秒以下，3 秒兜底），沿最后接近方向反向退离（0.8 秒且停稳，5 秒兜底），随后持续悬停并发布任务完成标志。节点重启前不会再次接近。

## 三、状态与预期效果

| 状态 | 行为 |
|---|---|
| 观察 | 默认状态，只发布零速度，不执行接近 |
| 锁定 | 等待连续稳定的同帧目标数据 |
| 远段接近 | 以受限速度沿预测视线缩短距离 |
| 末段接近 | 降低速度，增加小幅运动提前量 |
| 接触窗口 | 以最低速度继续接近，同时监听接触组合信号 |
| 制动 | 接触确认后立即发布零速度 |
| 退离 | 沿最后接近方向反向低速移动 |
| 悬停 | 退离结束后保持零速度，并只发布一次任务完成标志 |
| 中止 | 数据陈旧、状态失效、越界、接触窗口超时等情况下锁定为零速度 |

预期效果是：稳定识别移动软靶后，拦截器不再维持原有安全间距，而是根据图像延迟和目标角运动形成受限的预测视线，沿该视线先慢后快逐级加速接近并完成一次接触。由于只有单目，绝对距离仍依赖靶标尺寸一致性，最终参数必须通过地面、系留和低速分级试验标定，不能把默认值直接视为外场定值。

### 6. 实时低速软靶试验

只有在完成地面和影子验收、现场封控、飞手确认、相机标定确认、接触防护件确认、旧进程清空后，才运行：

```bash
ros2 launch falcon_contact search_contact_v0.launch.py \
  adapter_mode:=live \
  field_authorized:=true \
  contact_authorized:=true \
  allow_live_control:=true \
  calibration_ready:=true \
  contact_hardware_ready:=true \
  residual_process_check_passed:=true
```

这条命令仍不会自动解锁、起飞或切换模式。飞手手动解锁并起飞到安全高度，确认悬停稳定后再手动进入外部控制模式。任何异常立即由飞手退出外部控制模式。

## 七、停止顺序

1. 飞手先退出外部控制模式，确认飞机已回到人工控制并稳定悬停。
2. 在接触链路终端按一次“控制键加字母 C”，等待所有节点正常退出。
3. 在证据记录终端按一次“控制键加字母 C”，等待记录关闭并生成元数据文件。
4. 最后停止相机和图像记录链路。
5. 着陆后再检查记录文件，不要在飞行中强制结束安全适配进程。

## 八、主要参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `required_lock_samples` | 8 | 连续稳定帧数 |
| `capture_timeout_s` | 0.45 | 图像采集数据允许的最大真实年龄 |
| `prediction_control_delay_s` | 0.08 | 控制与执行响应余量 |
| `prediction_guidance_lead_s` | 0.12 | 末段附加运动提前量 |
| `prediction_maximum_horizon_s` | 0.45 | 总预测时长硬上限 |
| `prediction_maximum_offset_rad` | 0.12 | 最大预测偏角 |

| `terminal_speed_mps` | 2.20 | 末段接近速度 |

| `maximum_horizontal_mps` | 4.5 | 总水平速度限幅（硬上限 4.5，不低于接触段速度，launch 可覆盖） |

| `lead_maximum_distance_m` | 1.0 | 瞄准点前移距离上限（米） |
| `lead_maximum_time_s` | 1.0 | 提前量时间上限（秒） |
| `lead_deadband_mps` | 0.25 | 低于该横向速度视为静止，不做提前 |
| `contact_loss_stale_s` | 0.20 | 接触窗口内判定“目标开始丢失”的配对超时 |
| `phase_downgrade_hold_s` | 0.5 | 阶段降级滞回时长 |
| `settle_speed_mps` | 0.4 | 制动/退避的停稳速度阈值 |
| `brake_max_hold_s` | 3.0 | 制动段兜底上限（秒） |
| `retreat_max_duration_s` | 5.0 | 退避段兜底上限（秒） |
| `brake_hold_s` | 0.6 | 接触确认后零速制动保持时长 |
| `terminal_range_m` | 3.0 | 进入末段的单目距离门限 |
| `contact_range_m` | 1.0 | 进入接触窗口的单目距离门限 |
| `contact_window_timeout_s` | 1.5 | 接触窗口最长持续时间（冲刺版收紧） |
| `minimum_height_m` | 0.5 | 贴地保护下限：低于该高度接近/退避指令不再下降；不再作为任务门控（2026-09-11 修订，气球靶为 1-2 米低空目标） |
| `maximum_height_m` | 30.0 | 仅保留参数兼容，高度不再阻止任务 |
| `maximum_origin_radius_m` | 50.0 | 相对启动点的水平半径边界 |
| `measurement_hold_timeout_s` | 3.0 | 接近/末段数据断流保持上限，超时才中止 |

首次实飞不要提高速度、预测时长或接触窗口时长。冲刺版首次实飞必须从悬挂静止气球开始（此时提前量自动处于死区，行为与无提前量一致），先以 launch 参数把三段速度临时压回 1.0/1.5/2.5 验证全链路，再逐级放开到默认 1.5/2.2/3.5，最后再引入缓慢移动靶；每次只改一个参数。若状态中 `prediction_limited` 长时间为真，应先降低图像处理和传输延迟，不能用继续增大预测上限来掩盖链路问题。

代码还设置了不可由启动参数突破的保守上限：总预测时长不超过零点六秒，预测偏角不超过零点二弧度，远段、末段、接触速度分别不超过每秒二点零、三点零、四点五米，总水平限幅不超过每秒四点五米、总垂直限幅不超过每秒三点五米。冲刺轮廓要求三段速度逐级递增（接近 ≤ 末段 ≤ 接触），否则节点拒绝启动；总水平/垂直限幅必须不低于接触段速度，否则冲刺速度会被二次限幅钳回。

## 九、分级验收

1. **桌面回放**：用历史记录验证同帧配对、采集年龄、预测限幅、状态转换和中止条件。
2. **静态软靶影子试验**：飞机不上桨，只检查目标尺度、角速度和预测方向。
3. **系留低推力试验**：验证坐标轴方向、飞手接管和零速度制动，不允许实际接触。
4. **悬挂软靶低速试验**：目标静止，接触速度不高于默认值，验证防护件和接触判定。
5. **缓慢移动软靶试验**：从很低横向速度开始，每次只改变一个参数，并完整保存图像、检测、状态和飞控记录。

## 十、必须注意

- 目标必须轻、软、无尖锐边缘，不得放置人员附近；建议使用远离桨盘的柔性接触杆或完整防护罩，让接触部位先于桨叶触靶。
- 单目距离会随目标姿态、遮挡和检测框抖动变化。更换靶标尺寸、检测模型、图像分辨率或镜头后，必须重做检测框距离标定。
- 当前搜索相机安装补偿按滚转负九十度、镜头向机头倾斜约十度处理。重新安装相机后必须先做地面坐标轴验收。
- 图像传输和算法延迟直接进入预测。实测采集年龄超过零点四五秒时，节点会中止而不是继续追踪旧目标。
- 进入接触窗口后若一点五秒内没有可靠接触信号，节点中止并悬停，防止持续盲冲；按冲刺接触速度三点五米每秒与约一米进入距离计算，理论穿越时间不足一秒，超时上限留有约一倍余量，擦过目标后最多再冲刺约四米。
- 移动靶专用约束：线性提前量依赖角速率估计质量，目标机动或检测抖动会直接进入瞄准点；若状态中 lead.limited 长时间为真，说明靶标速度或接近几何超出限幅，应降低靶速或调整进入方向，不要调大提前量限幅来硬追。追击 2 米每秒靶标时接触窗口内相对闭合速度最低约 1.5 米每秒，飞手发现长期追不上时应果断接管，避免长时间贴尾追逐。
- 现场必须设置地理围界、独立观察员和人工接管口令；飞手双手不得离开遥控器。
- 不得同时启动原单搜索伺服链路与本链路；它们会竞争同一组上游设定值主题。
- 接触后不应立刻停桨。即使任务完成标志已发布，也应由飞手在确认悬停和落地后按正常流程上锁。

## 〇、任务一句话

跟踪稳定后主动进入 AIM：把"等几何碰巧对准"改成"令姿态对准"——
这是定案概念"跟踪→姿态瞄准→角度门触发"中"姿态瞄准"四字的补全。
开火成功后原地旋转 360°（位置保持不破坏），作为人工核验"已激发"
的标志，提示飞手准备切出 offboard。

## 一、控制层三种模式的优劣（本任务的选型依据）

| 维度 | 速度控制（现状跟踪段） | 加速度控制 | 姿态控制（本次引入） |
|---|---|---|---|
| 倾角如何产生 | 速度需求的副产品（PX4 内环） | 直接对应（a=g·tanθ，一步到位） | 直接命令（瞄谁指谁） |
| 响应带宽 | 慢（速度误差→MPC→姿态，多一拍） | 快（前馈直达倾斜） | 最快（姿态环几十 ms 级） |
| 位置/速度闭环 | ✅ 外环天然闭环 | ⚠️ 需另配速度环收拾漂移 | ❌ 放弃（倾斜必漂移） |
| 高度管理 | ✅ 自驾仪闭环 | ✅ 可闭环 | ⚠️ 姿态+油门需自管推力 |
| 悬停保持 | ✅ | ❌ 静倾角物理上不可持续 | ❌ 同左 |
| 安全性 | 好（速度上限直接钳制） | 中 | 边界变化（倾角指令需自钳） |
| PX4 接口 | TrajectorySetpoint.velocity 成熟 | velocity 模式下 accel 字段是前馈语义 | VehicleAttitudeSetpoint（四元数+推力），ob.attitude=true |
| 适合的任务 | 跟踪（持续、要闭环） | 瞬态机动 | **瞄准（短时、要指向）** |

**结论与分配**：跟踪=速度控制（外环稳定，不动）；瞄准=短时
（0.3-0.8s）姿态级指令。混合架构是正确形态，物理边界（静倾角
不可持续、瞄准期间必漂移 tanθ×g×t）决定了 AIM 必须是脉冲式。

**路线定案（2026-10-14 用户二次定案：B 加速度前馈为主，A 真姿态为升级路径）**

### B 主路线实现逻辑（~25 行，零新增标定）

物理依据：tanθ = a/g 精确成立，加速度前馈就是借 MPC 的姿态通道
（PX4 速度模式 MPC 拿到 accel 前馈后内部直接转姿态设定点），推力
模型/高度环/漂移兜底全由 PX4 闭环负责。

```
进入条件：aim_mode_enabled && est 有效持续 ≥aim_enter_delay
         && 武器授权（strike 话题）&& 目标速度 ≤aim_max_target_speed
每拍（50Hz）：
  预测点 = est_pos + est_vel × t_tof      # t_tof = |est_pos|/55
                                           # ——与火控 PIP 同口径
  θ_aim = atan2(|预测点水平|, |est_z|)
  θ_aim = min(θ_aim × aim_tilt_compensation, aim_max_tilt_rad)
  a_cmd = g·tan(θ_aim) × 预测点水平单位向量
  sp.velocity = {0, 0, vz_hold}           # 悬停，垂直环照旧
  sp.acceleration = {a_cmd_x, a_cmd_y, 0} # 前馈→倾斜
  控制模式：velocity 与 acceleration 两个位同开
超时 aim_timeout_s 未开火 → 回 VELOCITY_TRACK（指令斜坡自然衔接）
```

- 补偿系数 aim_tilt_compensation 默认 **1.15**（速度环反作用使实际
  倾角欠 10-15%，实测标定）；可选自适应：多次 AIM 后轴误差稳定
  残留在某值而上限是瞄准角时自动上调。
- **指向验证哲学（本架构最关键的一条）**：火控的 axis_err 用实测
  姿态（vehicle_attitude）对实测瞄准线（估计）独立计算，2° 门验收
  的是**真实指向**而非指令——瞄准指令欠量只影响开门早晚，不影响
  打的准；补偿错了方向则门不开、超时安全回退。永远不信任指令，
  门只认实测。
- 预瞄：瞄准目标=PIP（预测拦截点），与火控解算同口径；稳态跟踪
  相对速度≈0 提前量小，穿越/瞬态时提前量重要（5m/s×0.2s=1m≈7.6°）
  ——彼时火控本靠几何扫掠触发，与 AIM 自然分工。

### A 升级路径（若 B 精度/权威不足时启用；前馈与反馈清单）

切 `ob.attitude=true` 发 VehicleAttitudeSetpoint（q_d +
thrust_body[2]，NED 机体系 z 朝下：**thrust_body[2]=−油门需求**）。

**必需前馈**：
1. **推力倾角补偿**：thrust_body[2] = −(T_hover/cosθ_aim)。
   T_hover=MPC_THR_HOVER=0.46；θ=20°→0.49、36°→0.57。缺了它
   一倾斜垂直分量就小于重力，立即掉高。
2. **q_d 平滑生成**：进入 AIM 时从当前姿态限速率 ramp 到瞄准姿态
   （建议 1.5-3 rad/s，同 yaw 伺服量级）——姿态环拿四元数误差
   算角速率，设定点跳变=机身猛抽。消息自带 `reset_integral=true`
   在切入时清姿态环积分（模式切换防积分风up）。
3. **yaw 分量锁定**：q_d 用"tilt-toward-aim + yaw=yaw_sp"构造
   （先算期望机体 z 轴 = 瞄准线方向（NED 取负号朝下约定），再用
   yaw 参考方向正交化出 x 轴，组装旋转矩阵→四元数）——保证倾斜
   只发生在瞄准轴、机头不漂转。

**必需反馈（A 路线的真正缺口在反馈不在前馈）**：
4. **高度微环（自制 10 行 PD）**：真姿态模式没有高度闭环，开环
   0.46/cosθ 的误差（实机电压凹陷/推力曲线 5-10%）×0.8s 超时
   会掉高 0.1-0.3m。修正：thrust_body[2] += −(kp_z·(z−z_sp) +
   kd_z·vz)/cosθ，钳制总量 [-0.70,-0.30]；z_sp=进入 AIM 时刻
   高度。
5. **水平漂移预算**：AIM 期间无水平闭环，漂移=tanθ·g·t（20°@
   0.8s≈1.1m 极限；正常 2° 即打 0.2-0.3s 内完成，典型 0.3-0.5m
   朝目标方向——方向无害）。超时回 VELOCITY_TRACK 时**速度种子
   用 lp_->vx/vy**（现有 slew 限幅自然制动）。

**实机注意**：电压凹陷（AIM 脉冲 0.3-0.8s 内影响小，可依赖 PX4
推力学习）；MC 姿态环增益（MC_ROLL/PITCH_P 等）为实机标准调参项；
仿真侧 thrust 模型理想，冒烟时对照高度轨迹验证第 4 条环的必要性。

## 二、完整版方案

### 1. 状态机扩展（guidance，TRACK 内子状态）

```
VELOCITY_TRACK ──(aim_mode_enabled && est_ok 持续≥aim_enter_delay
                  && 武器授权 && 目标速度≤aim_max_target_speed)──▶ AIM
AIM ──(开火/DONE)──▶ SPIN ──(转满 2π)──▶ DONE（位置保持）
AIM ──(超时 aim_timeout_s 未开火)──▶ VELOCITY_TRACK（重新稳定再来）
```

- **武器授权信号**：目前授权判据在 strike 节点内部（就位锚+
  delay+stable_track），guidance 不知道。**新增小改动**：strike
  发布 `/tracking/weapon_authorization`（Bool，10Hz 或 latched），
  guidance 订阅作为 AIM 进入条件——单一真源，避免两边各算一套
  （此前 takeoff-ready 就是同样模式）。
- **瞄准目标**：θ_aim = atan2(|est_xy_预测点|, |est_z|)，方向 =
  PIP（est 位置+速度×tof 量级，直接用 est_lp+vel×0.2 预测即可，
  与火控 PIP 不必严格一致——火控自己会算）。yaw 保持当前 yaw_sp
  （宽轴对准航线不动）。
- **倾角钳制**：aim_max_tilt_rad 默认 **0.35 rad（20°）**——远低于
  36° 天花板和 37° FOV 边界，安全优先；实测不够再谈。
- **超时回退**：aim_timeout_s 默认 0.8s。回 VELOCITY_TRACK 后重新
  计稳定时间（防抖）。
- 迎敌高速段：aim_max_target_speed_mps 默认开放（∞），完整版=常规
  进入；若矩阵显示高速段 AIM 干扰几何扫掠对准，再收紧此参数。

### 2. 360° 旋转标志（SPIN 段）

- 触发：shot 事件（已有订阅）→ 不再直接 DONE，先进 SPIN。
- 行为：**位置+高度保持照常**（速度模式位置保持与 yaw 旋转完全
  兼容），yaw_sp 以固定速率推进 spin_total_rad（默认 2π），方向
  固定顺时针（从上往下看），速率 spin_rate_rad_s 默认 **1.8
  （≈103°/s，一圈 3.5s，人工可辨识）**。
- 转满后进 DONE 常规保持。
- 参数：spin_flag_enabled（默认 true）/ spin_rate_rad_s /
  spin_total_rad。
- 用途链：飞手看到旋转 → 核验已激发 → 拨杆切出 offboard（rc_gated
  会同拍停 setpoint，`offboard exited → standby` 日志）。
- 注意：yaw 推进用 unwrap 累加（现有 yaw 伺服同款手法）；SPIN 期间
  估计失效不影响（位置保持锚定当前位置）；单发闩锁在火控侧，旋转
  不会引起二次开火。

### 3. 火控侧改动（最小）

- 仅新增授权话题发布（§二.1）。
- 2° 即打/4° 兜底/LOS 门/单发闩锁全部不动——AIM 只是制造对准。

### 3. 为什么需要 AIM（1 m/s 档失败机理，已实测钉死）
1 m/s 追击失败轮诊断（授权后 29 样本）：range 7.5-7.7 ✓、LOS 率
0.15-0.30 ✓、est/auth ✓，**唯轴误差恒卡 4.4-6.8°**（>4° 兜底门）。
机理：稳态跟踪拖尾 ~0.7m → 瞄准线前倾 ~5.7°，而稳态跟踪无需加速 →
机体水平 → 轴误差=瞄准线倾角恒定。高速档靠起步斜坡的加速倾斜
（3 m/s→8.7°、5 m/s→14°）穿越对准窗口；1 m/s 斜坡只 0.5 m/s²→
2.9°，对不上。**AIM 用主动倾斜直接补这个差**，是低速档的正解。

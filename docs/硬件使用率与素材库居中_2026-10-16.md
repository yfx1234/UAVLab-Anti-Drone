# 硬件使用率与素材库居中（2026-10-16）

本轮完成通用只读 CPU/GPU 使用率、模组供电说明及素材库整体居中。专项链控制、运行实现与既有前端渲染未修改；部署不重启或停止采集进程。

## 实现

- 硬件快照 schema 2 沿用两秒缓存，CPU 根据同次启动的系统计数器差计算；GPU 读取已有 sysfs 忙碌比例。没有新增 GPU 运算、常驻进程或阻塞采样等待。
- CPU 首次采样、数据缺失、断线或过期均显示未知；真实 GPU 0% 正常显示，越界数值不显示为有效读数。
- “模组供电”仍来自 INA3221 的 VDD_IN；其读数用于供电监测，不能代替电池电压或换算电量。前端保留来源提示。
- 素材库最大宽度由来源栏、24px 间距和原有按窗口高度缩小的视频宽度组成，通过 margin-inline:auto 整体居中。窄屏保留自然堆叠、完整比例与原生播放控件。

## 验证与边界

新增计数器测试先观察缺失字段及前端渲染失败，再实现并通过：传感器/缓存 9 项、前端状态 12 项、既有传输新鲜度 3 项，共 24 项通过。包含 guest 不重复计数、GPU 单位与真实零值、缓存命中、首次采样、不同 boot、时钟回退、CPU 计数回退及异常 idle 差值。相邻采样间隔超过十秒时重建 CPU 基线，避免断开后把长时间平均值冒充当前负载。

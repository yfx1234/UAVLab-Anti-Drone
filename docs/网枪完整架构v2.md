# 网枪拦截完整架构 v2（面向实机）

> 2026-10-12 起草。定位：替代此前的简化版（纯深度单通道），补齐原版上游链
> 的方位接近段，按实际双目 SDK 行为建模深度退化，加入目标速度前馈。
> **目标：上实机。**

## 1. 传感模型（三区，按双目 SDK 实际行为）

| 区域 | 距离 | 深度状态 | 观测输出 | 引导方式 |
|---|---|---|---|---|
| 远区 | >12m | SDK 硬截断，无深度 | `SearchObservation`（双目方位均值） | 方位伺服接近（bearing-only） |
| 过渡区 | 10~12m | 不稳定，时有时无，精度差 | `DepthObservation`（depth_valid 按概率翻转；深度噪声 ×4） | 方位持续 + 深度有就融合（协方差自适应放大） |
| 近区 | <10m | 稳定 | `DepthObservation`（depth_valid=true） | 全力闭环（方位+深度 → IMM → 火控） |

### 1.1 传感器节点改造（logical_camera_simulator）

新增参数：
```
depth_reliable_max_m: 10.0        # 近区上界
depth_cutoff_m: 12.0              # SDK 硬截断
depth_unstable_valid_probability: 0.4  # 过渡区每帧 depth_valid=true 的概率
depth_unstable_noise_multiplier: 4.0   # 过渡区深度噪声放大倍数
```

行为：
- range < reliable_max：`depth_valid=true`，正常噪声
- reliable_max ≤ range < cutoff：以概率 p 置 `depth_valid=true`，
  深度值噪声 ×multiplier；`depth_valid=false` 的帧仍输出方位+像素
- range ≥ cutoff：`depth_valid=false`，仅方位（`depth_valid` 字段为 false
  的 DepthObservation；消费者按 SearchObservation 语义解析方位）

实机对应：SDK 深度截断行为映射为同样的 `depth_valid` 规则；>12m 时
深度相机驱动不出深度帧，但双目 YOLO 检测（左右目）仍然出 bbox →
取两目方位均值 → 等效 SearchObservation。

### 1.2 观测接口

复用现有 `anti_drone_interfaces` V1 双接口：
- `SearchObservation`：>12m 时由感知节点发布（双目方位均值）
- `DepthObservation`：≤12m 时发布（depth_valid 按上述规则）

**不需要新增消息**。感知节点（实机为 DeepStream/YOLO 检测节点）
根据双目深度可用性自动选择输出哪种。

## 2. 估计器（IMM CV/CA/CT + 协方差自适应）

### 2.1 IMM 不变（已实现）

CV/CA/CT 三模型、10 维状态（含转弯率 ω）、转移概率矩阵、贝叶斯权重。
详见开发手册 §3.6。

### 2.2 新增：测量协方差自适应

```
if depth_valid:
    if range < reliable_max:      # 近区
        covariance = 正常（像素 σ → 角度 σ + 深度 σ）
    else:                          # 过渡区（10~12m）
        covariance × depth_unstable_noise_multiplier²
else:
    # 仅方位：只更新位置的水平分量（深度维不更新，协方差自然膨胀）
    # 等效于方位-only 观测：H 矩阵退化为 2×10（去掉 z 行）
```

这需要修改 `relative_estimator` 的 `on_observation`：
- 新参数 `depth_reliable_max_m`、`depth_unstable_noise_multiplier`
- `depth_valid=false` 时：H 从 3×10 降为 2×10（只取方位分量），
  或者等效地：把 z 方向的测量方差设为极大（如 1e6）
- 过渡区深度可用时：测量协方差 ×multiplier²

### 2.3 新增：>12m 方位-only 跟踪

当 `SearchObservation` 输入时（方位角 + 仰角，无距离）：
- 构造 2 维测量：水平方位 φ、垂直仰角 θ
- 转换到 NED 单位向量（用当前姿态四元数）
- H 矩阵：位置 → 方位/仰角是非线性变换，用 EKF：
  z = [φ, θ] = [atan2(ned_y, ned_x), atan2(-ned_z, √(ned_x²+ned_y²))]
  H = ∂z/∂state（2×10 雅可比）
- 距离不可观 → 距离维协方差自然膨胀 → IMM 权重仍然工作

这是标准 bearing-only EKF，工作量约 1 天（含雅可比推导和单测）。

## 3. 引导与制导

### 3.1 状态机（继承原版上游 B0~B17 简化）

```
┌─────────┐  range>12m  ┌──────────────┐  range≤12m ┌─────────────┐
│  SEARCH │────────────→│ BEARING_ONLY │───────────→│ DEPTH_TRACK │
│ (扫描)   │             │ (方位伺服接近) │            │ (深度闭环)   │
└─────────┘             └──────────────┘            └─────────────┘
                              │ 估计valid                │ 距离∈[6,10]
                              │ + range_est<12           │ + 轴误差≤门
                              ↓                          ↓
                        ┌──────────────┐          ┌─────────────┐
                        │  DEPTH_TRACK │────────→│   FIRE      │
                        │  (保持6.2m)  │          │  (单发闩锁)  │
                        └──────────────┘          └─────────────┘
```

三个状态（比上游 B0~B17 大幅简化，因为网枪链不需要搜索扫描/再攻/修正）：

| 状态 | 进入条件 | 引导律 | 退出条件 |
|---|---|---|---|
| BEARING_ONLY | range>12m 或无深度 | 方位伺服：v = gain_az × 方位误差 + v_ff × 目标速度估计 | 深度有效（depth_valid 连续 3 帧）|
| DEPTH_TRACK | 深度有效 | 位置保持：v = gain_pos × 相对位置 + **目标速度前馈** | 距离∈[6,10] ∧ 轴误差≤门限 |
| FIRE | 全门通过 | — | 单发闩锁（不可逆） |

### 3.2 目标速度前馈（最关键的新增）

```
速度指令 = gain × 相对位置  +  K_ff × v_target_est
```

其中 `v_target_est` 来自 IMM 的速度估计（三模型加权融合输出）。

效果：稳态滞后从 v/gain 降到 ≈0（跟踪器与目标同速飞行），
5m/s 目标的斜距从 10.4m 锁定到 6.2m，彻底解决出窗问题。

参数：`K_ff` 默认 1.0（全前馈），可调 0~1。

### 3.3 方位伺服接近（BEARING_ONLY 段）

```
给定：目标方位 φ（NED 水平角）、仰角 θ
控制：
  航向 = φ（机头对准目标方位 → 偏航律 §12.5）
  水平速度 = min(k_az × φ_err, max_speed_approach)
  垂直速度 = 保持当前高度（等深度有效后再爬升到位）
```

不需要距离信息——只要朝目标方向飞，距离总会缩短到 12m 以内。
接近速度建议 3~4m/s（追踪机最大速度）。

### 3.4 终端保持 + 姿态瞄准

DEPTH_TRACK 段（深度有效后）：
- 位置环：v = gain_pos × rel_pos + K_ff × v_target_est → 消除水平滞后
- 垂直：保持目标下方 6.2m（takeoff_height = target_height - 6.2）
- 姿态：不主动控制倾斜瞄准（当前 2°/4° 门限已够用，姿态抖动
  自然穿越窗口；后续可加终端对准渐入提高触发率）

## 4. 火控（不变，已验证）

全部沿用 v4 定稿：1°/2°（标准）或 2°/4°（放宽）即打 + 0.2s 兜底 +
单发闩锁 + LOS 率门 + 距离门 [6,10] + 本机速度补偿 + 蒙射接口默认关。

唯一改动：距离门用估计器输出的距离（不再硬编码），参数已连通。

## 7. 与简化版的差异总结

| 维度 | 简化版（当前代码） | 完整版（本方案） |
|---|---|---|
| 传感 | 硬截断 10m | 三区（>12 方位 / 10-12 不稳定 / <10 稳定） |
| >10m 引导 | 无（全链断粮） | 方位伺服接近（bearing-only） |
| 估计 | 仅深度输入 | 方位-only + 深度自适应协方差 |
| 制导 | 位置保持无前馈 | 前馈消除稳态滞后 + 三状态机 |
| 5m/s 目标 | 斜距 10.4m 出窗 | 斜距锁定 6.2m |

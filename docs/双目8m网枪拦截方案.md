## 2. 网枪简单模型（不变，v3 §2）

V5-C 档：`muzzle_speed=55 m/s`、覆盖半幅 1.5 m（3×3 正方形）、展开
0.15 s、有效 [6,10] m、单发。接口 `time_of_flight(range)=range/55`、
`covered(x,y,range)=|x|≤1.5∧|y|≤1.5∧6≤range≤10`。

## 3. 火控律（v4 定稿）

```
开火 = 授权门（armed∧offboard∧原点锁定∧高度门∧attack_enable_delay）
     ∧ 距离门 range∈[6,10]
     ∧ LOS 角速率门
     ∧ 择时（三支任一，无 0.04s 去抖）：
        主支：轴误差 ≤ 1°        → 立即开火（不等变差）
        兜底：1°<误差≤2° 持续 0.2s → 开火（抖动环境下难触发，低优先实现）
        蒙射：见 §4
     ∧ 单发闩锁（触发后永久闭锁）
预测：射击方向对准 IMM 预测 tof(+展开0.15s) 时刻目标位置
```

## 4. 蒙射支（最后机会射击，新增设计，待确认）

**动机**：3×3 覆盖在 8m 处等效半角 ≈ 10.6°，即使稳定瞄准窗（1°/2°）
未达成，只要对 IMM 预测点的瞬时误差不超过覆盖余量，单发仍有可观命中
概率——"够不着完美窗就蒙一把"符合单发任务的最优策略。

```
蒙射触发（两条件任一，且弹未用、IMM 预测有效）：
  A 窗口即将丢失：range + rate × T_exit 将穿出 [6,10]（T_exit≈tof+0.1s）
  B 任务超时：engagement 计时超时仍未发射
蒙射门：预测瞄准误差 ≤ 8°（=10.6° 覆盖半角留 2.6° 余量，参数化）
动作：对 IMM 预测的 tof 时刻位置方向发射（同主支闩锁与信号）
```
默认参数建议启用 A、B 皆开；待实测命中率数据后调整。

## 12. 仿真前补充决策（2026-10-11）

### 12.1 站位与几何（修订 §7 布置）
- 不要求严格正下方：向正下方方向逼近即可；到达下方后保持 **约 6.2m**
  （仍在 [6,10] 窗内，角度裕度更大：1.5m 半幅 @6.2m ≈ 13.6° 半角）。
- **大倾斜角也可触发**：现火控门本来就是纯角度制（轴误差 vs 预测视线），
  与机体倾斜/斜距几何无关——倾斜大只要轴误差进窗即触发，无需改代码。

### 12.2 裁判坐标系
- strike 事件中估计量为相对系（frame_id=pursuer_local_ned）；
  裁判桥统一**相对系→绝对系转换**后再进 3×3 判定（S1 实现项，不改消息）。

### 12.3 延迟补偿方案（只设计，暂不实现）
现实参数：网枪触发延迟 ~0.5s、相机识别延迟 ~0.2s。方案：
- **相机 0.2s**：V1 接口强制 header.stamp=曝光时刻——只要时间戳诚实，
  估计器按时间戳消费即自动对齐；残余影响=数据年龄 0.2s 的预测误差
  （2m/s 目标、速度估计差 0.5m/s → 仅 ±0.1m）。**核对项**：实机流水线
  时间戳必须是采集时刻而非推理完成时刻，否则需 `detection_latency_s`
  参数显式回拨。
- **触发 0.5s**：开火决定在 T 时刻、网离膛约 T+0.5、到达 T+0.65：
  1) 瞄准提前量 horizon 从 (tof+展开=0.30s) 扩为 **(0.5+tof+展开≈0.8s)**，
     新参数 `trigger_delay_s`；本机速度补偿的 lead 同步扩到全 horizon
     （0.5s 内本机漂移 1m/s→0.5m，与覆盖半幅同量级，必须补）；
  2) 开火门从"当前误差"改为"**网到达时刻的预测误差**进窗"（决策量前移）；
  3) IMM 的价值随 horizon 变大而放大：0.8s 直线目标误差 ≈0.4m 可控，
     机动目标 2m/s² → 0.5at²≈0.64m，圆周场景靠 CT 模型压回。
- 实测项：两段延迟都应实测标定（硬件直触发脉冲优于走 ROS 话题）。

### 12.4 角度放宽测试档
- 新增 `config/netgun_strike_relaxed.yaml`：**2° 优选即打 / 4° 硬门(0.2s)**，
  与标准档（1°/2°）在 S4 首跑时做 A/B 对比，记录触发率/命中/触发时误差。

### 12.5 偏航控制（回答"机头对准航向"）
- 权限：offboard 下 yaw 由 TrajectorySetpoint.yaw（位置模式）或姿态
  四元数（姿态模式）下发；上游链走姿态设定值，yaw 分量由制导决定。
- 推荐两段律：**转段 yaw=航向**（atan2(地速)，速度小时保持上次值）；
  **末端下方保持段 yaw=目标视线方位**（相机长边沿机头，机头对目标
  使目标落在 FOV 长边方向，前后向裕度最大；上方相机 yaw 对可见性
  本身对称，收益在 FOV 长边余量与气动一致性）。
- 实现位置：S1 的 tracker 参数（simple_below_tracker 的 yaw 策略核对，
  无暴露参数则后续小改，列入 S1 检查项）。

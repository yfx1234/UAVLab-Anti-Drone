# QGC USB 自动重连修复

## 结果

NX 用户服务已部署 USB 设备身份监督：设备消失或 inode 改变时先停止并回收旧 MAVProxy，等稳定设备重新出现后启动新进程。监督只读取文件元数据，不打开或争读 USB。

用户在 QGC 连续操作的三次真实飞控重启都自动恢复；助手未在三次重启间重启转发服务。仅测当前硬件、固件和三次重启，不泛化为所有 USB 故障或长期稳定性认证。

## 已部署文件与参数

- `deploy/supervise_mavlink_usb.py`：每 0.25 s 检查稳定 by-id 路径身份，稳定 0.75 s 后启动，子进程退出最长等待 3 s 后强制清理。
- `deploy/install_qgc_usb_reconnect.py`：保留原 ExecStart 全部参数、Environment 与 WorkingDirectory，只添加监督前缀；安装前备份、原子替换，重载/重启失败时恢复原单位文件。
- 当前原始 UDP 输出全部保留：192.168.50.101:14550、192.168.50.101:14551、127.0.0.1:14555。未修改现有调用方。
- 重复执行安装器不会重启服务或重复包裹命令。
- 未更改飞控参数、固件、ROS 2 接口，也未由助手发送飞控重启、解锁、运动或击发指令。

# 感知单次流程参数与坐标输出核验

## 结论

按“启动相机 → 调整模型、输入分辨率、置信度 → 调整并保存等效尺寸 → 开启 YOLO → 只读接收感知数据 → 暂停 YOLO/结束相机”的顺序，8 组实机流程和 8 组隔离 SVO 回放全部通过。

本次只增加流程回归测试与验收记录，没有修改或重新部署生产算法、模型、界面。板端三份关键感知源码与电脑部署的 HTML 均与本地一致，SHA256 见结果文件。

## 对“淘汰旧批次”的准确解释

采集线程将图像和当时的参数放在同一个 Frame 中，推理线程可能正在处理上一帧。`set_detector` 更新模型/阈值后增加 detector_generation，清空待处理帧，并在推理开始、推理结束和发布前核对代次；不匹配的尚未发布结果被丢弃。这不会回写或重算已经输出、已经录下的数据。

用户的流程在保存尺寸时 YOLO 仍暂停，因此不存在携带旧尺寸的有效 YOLO 目标结果；开启时又会增加代次。之前提到的短暂旧尺寸风险只适用于 YOLO 已经开启时中途保存尺寸：该分支未单独增加代次，可能让在途旧帧输出。不能把这个边界扩大成日常先配置后开启也会串参数。

## 参数在每次流程中的行为

| 参数 | 生效与保留 |
|---|---|
| 模型、输入分辨率 | 界面将选中的输入尺寸映射到具体 model_id/引擎；启动相机和开启 YOLO 都显式传入所选 model_id。相机运行但 YOLO 暂停时也能绑定新模型；开启后加载对应引擎。 |
| 置信度 | 每次相机进程初始化为 0.55；界面调整与开启 YOLO 时都会传入当前输入值。应在每次流程中确认，不应假定上次阈值已持久保存。 |
| 等效尺寸 | 输入后必须保存；持久写入配置，下次相机启动会沿用最近保存值。更换目标或使用不同模型时，数值应按对应目标/模型适配。手动保存仍不等于完成实测标定。 |
| 坐标 | 检测框先从网络输入还原到相机原图，再按原图内参投影；不是拿网络输入分辨率直接配相机内参。 |

有效双目深度优先；没有合格深度时，尺寸估距使用 `Z = size / max(bbox_width/fx, bbox_height/fy)`，再计算相机光学坐标 XYZ（米，右/下/前为正）。只有尺寸估距分支会按尺寸直接缩放。目标贴边或过小时可能只有方向，此时 position_valid=false；未检出目标时目标列表为空。

## 实测与检查

- 实机使用原生产程序：界面实际可选的 4 个引擎，各完成两次独立启动、暂停状态设置参数/保存、开启、读取、暂停、停止。测试两组设置为 0.35 / 24.7 cm 和 0.85 / 30 cm。
- 同时核查 ROS 类型化观测与 JSON 观测：当前 run_id、model_id、代次、启用状态、置信度，以及每个目标的 size_prior_m、坐标有效性、XYZ 投影公式和距离公式。
- SVO 回放编译了生产源文件的隔离测试副本，只替换临时状态/配置/录像目录和输入源；坐标与推理逻辑未改。使用 ROS_DOMAIN_ID=71，与生产通信域隔离。仅回放保留的数据集第 2 段，不使用用户排除的人物场次或第 4 段后部。
- 两个只读订阅者同时接收，确认两者观察到重叠帧区间且各自的数据检查均通过；这只验证感知端多订阅者输出，不评估外部任务内部的缓存、坐标变换或控制逻辑。
- 36 项相关 Python/界面逻辑测试通过；板端 7 项原生 ctest 通过。新增 `tests/test_parameter_workflow.py` 直接执行当前界面的启动、保存、开启处理函数，验证跨两次流程的参数顺序。

## 测试边界及恢复

一次初始 2.5 秒订阅窗口未收到消息，已保留失败记录；测试工具随后增加“收到两个话题后再计时”的就绪条件，剩余组合重测通过。该次空窗口本身不能证明坐标算法故障，亦未据此更改生产程序。

测试后恢复原模型、自训 1920 × 1088 输入、置信度 0.55、尺寸 30 cm，相机运行且 YOLO 暂停，与测试前操作状态一致。生产二进制和原尺寸配置文件按 SHA256/字节比对均未改变；没有新建或修改录制素材。

验收证明的是本次范围内的参数传递、状态切换和坐标计算一致性，不等于所有模型/姿态/距离均达到同样物理测距精度，也不是长期外场稳定性认证。外部只读任务仍应按当前运行标识、时间、新鲜度与 position_valid 使用数据，不能保留无效后继续使用上一轮坐标。

汇总结果：`docs/experiments/2026-10-19-parameter-workflow.json`。完整取样、初次空窗口记录、脚本和临时测试构建记录保存在本机工作区同级 `parameter-acceptance-20261019/`，不将录制数据或引擎提交仓库。

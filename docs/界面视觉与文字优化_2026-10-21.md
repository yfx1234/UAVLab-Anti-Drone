# 工作台界面视觉与文字优化（2026-10-21）

## 起因

用户认为 8767 工作台的界面还能更好，尤其是很多文字呈现不好，并授权自由发挥。以改版前的 25a885a 在 2048×1010（2560×1440、125% 缩放的典型视口）实测：

- 页头两行，高 106px：品牌和工作区切换一行，状态文字另起一行，与左右内容不对齐；正常状态也是成片绿字，抢眼。
- 39 处可见文字小于 12px（11px 说明、表头单位、设备状态等）；中文标题用负字距，笔画挤在一起；标题字号 22/17/15px 混用。
- 控制栏标签堆在输入框上方，内容高 1029px、可视 830px，“板上录像”分组只露出标题，需要在栏内滚动。
- 禁用按钮与可用按钮底色几乎相同。
- 画面下方测量值是一行文字；就绪检查的状态点浮在文字中间；目标表把多项数值用斜杠拼在一格；多处信息用长串“·”连接；底部设备状态字小、层级弱。

## 变更（只改 `panel/index.html` 的样式与渲染输出；数据、控制逻辑、`dashboard.py`、RPC 与板端不变）

- **字号与字体**：正文 14px/1.55；区块标题 16px/600，分组标题 14px/600；控件与标签 13px；辅助说明 12px，全页最小 12px；品牌 18px；指标数值 18px/600，数字统一等宽。中文不再使用负字距。字体为 Segoe UI Variable Text / Segoe UI / 苹方 / Noto Sans SC / 微软雅黑，等宽为 Cascadia Mono / Consolas。
- **颜色**：中性灰阶，正文 #1d1d1f、次要 #6b6b70、辅助 #75757a（白底对比度 4.58:1）。状态色分文字色与圆点色（绿 #1c7550/#2f9f69、琥珀 #87590a/#dc9b2a、红 #b2333b/#e0484f），提醒用浅色底。禁用态单独配色（底 #f4f4f6、字 #a2a2a7），与可用按钮明显区分。
- **页头**：合为一行，高 64px：品牌、实时监看/素材库切换、状态胶囊（板子连接、时钟、相机、板上录像、拦截链）。胶囊白底轻阴影，灰点未运行、绿点正常、琥珀需注意、红色异常，后两者带浅色底。约 950px 以上保持单行；1100px 以下隐藏标题文字（读屏仍可读）、时钟胶囊和任务提示。
- **控制栏**：字段改为同一行“标签 | 控件”（标签列 72px）；估距等效尺寸在输入框内显示 cm。2048×1010 下控制栏内容 836px，全部可见，不用滚动。1100px 以下折叠后按每列至少 240px 分成至多 3 列，600px 以下单列。
- **实时画面**：下方改为四个指标块：采集帧率（Hz）、识别帧率（Hz）、画面时效（s）、图传码率（Mbps）。
- **拦截任务栏**：运行状态胶囊用浅底；进程号和日志时间合为“PID … · 日志 N 秒前更新”；就绪检查的状态点固定在左列，名称与值对齐。
- **目标表**：拆成 12 列：目标、置信度、定位、水平角 °、垂直角 °、X/Y/Z m、轴向深度 m、距离 m、深度有效率、深度判定。单位写在表头，数值右对齐；表格宽度小于 880px 时按容器查询收紧内边距，1400–1500px 视口下 12 列不需横向滚动。
- **素材库**：场次详情改为键值列表（标签列 58px），补充信息以小字跟在值后；重命名按钮加铅笔图标；视频信息中文不在词中断行。
- **设备状态**：标签 12px、数值 15px/600，正常、注意、异常用颜色区分。

## 第三轮追加（2026-10-21）

用户反馈：两侧模块下方偏短，和中间列不对称；就绪检查各行之间的横线多余；发射区的“自动单发 + 手动兜底”和“单发闭锁：自动与手动共用，任务内仅一次”两行文字不需要。

- **两侧对齐**：左侧控制栏和三列模式下的拦截任务栏在网格中拉伸到中间列的高度，最大高度为可视高度减去页头、健康栏和 32px（顶部 8px 加底部 24px）。页面不需滚动时三列同时结束；需要滚动时两侧填满可视高度，滚到底时与目标表底边齐平。内容超出时仍在卡片内滚动，内容较少时卡片底部留白。
- **就绪检查**：去掉行间分隔线，检查列表与下方“原始日志 / 操作要点”折叠区之间的横线一并去掉，靠行距和行首圆点成组。
- **发射区**：删去上述两行文字。默认模式（自动单发 + 手动兜底）不显示模式文字；只有“仅自动开火”“仅手动发射”等非默认模式才用琥珀色显示。单发闭锁规则仍写在“操作要点”和发射确认框里。
- **截断修复**：宽卡片中就绪检查分两列时，较长的值（如“已停发 · 飞控数据不可用”）在 1280px 下被截断，现在按词换行。

验证：沙箱模拟后端覆盖真机停发心跳、运行就绪、已闭锁、离线，宽度 2048×1010、1440×900、1366×768、1280×800、1100×800、1024×768、390×844：无脚本错误、无水平溢出、文字无截断，可见文字无小于 12px。底边实测：2048×1010 下两侧卡片占 72–952px，与滚到底时目标表底边一致；2048×1300 下三列都在 1176px 结束；1280×800 下控制栏底边与目标表底边同为 742px。板上录像进行中（模拟的已闭锁场景）时，2048×1010 下控制栏内容为 938px，高于卡片可用的 880px，仍在栏内滚动（与本轮修改前相同）。

## 四、触发率差距机理（已定位，非算法问题）

1. **统计口径**：镜像每格 12 轮取比例；Gazebo 每格 1 轮伯努利样本。
   镜像逐格触发率本身 75-100% 波动，单轮 Gazebo 天然放大方差。
2. **起跑瞬间对齐统计**：火控门比较"含提前量的瞄准方向"与"机体轴"。
   四旋翼机体轴只在加速时倾斜——开火窗口依赖目标起跑瞬间的加速倾斜
   与瞄准方向对齐。镜像悬停对齐稳态 ±1.2°（湍流模型）；Gazebo 实测
   悬停轴误差在 0.8°-6.7° 震荡（速度设定点无位置保持 → 位置游荡 +
   估计延迟），起跑瞬间若恰在 >4° 相位则错过窗口。
3. **逃逸死锁**：目标 5m/s vs 追踪机水平上限 4m/s，起跑后 ~4s 斜距
   冲破 12m 相机硬截断 → 观测断流 → 交战永久结束（无再捕获机制）。
   镜像同参数但因起跑即触发，规避了此问题。
4. circle 场景目标角速度恒 0.5 rad/s = LOS 率门限，天然卡门
   （镜像同参数下 circle 触发也最晚，t_eng 1-5s）。

## 十二、迎敌@5 边界深查（2026-10-13，不动任何定案门限）

**结论**：迎敌@5 在现有约束下处于 1-2° 的边缘差距，非时序问题。

## 十四、深度模型平滑化（2026-10-13 用户定案，最终版）

**背景**：实机深度来自 YOLO 识别 + 自研估深算法（非 SDK 深度）——
15m 内准确，15m 外仍可测、精度下降。故删除三区模型的概率丢弃
（40%）与硬截断（12/16m）。

**新模型**：<15m 正常噪声（0.1m）；>15m 噪声与协方差按 (d/15)²
连续增长（双目视差误差∝距离²），IMM 依协方差自然降权。有无深度
信息之间无阶跃——光学视场（H74°/V45°）是唯一的可见性门。

**验证**：40m 迎敌逼近探针，观测随目标进入视场锥自然开始，
主支开火命中 miss=0.25m@5.64m。

**注意（实现坑）**：logical_camera_simulator 的 fault model 返回
const 样本，噪声须作用于深度副本并按比例缩放位置——旧代码的
`(void)noise;`（不稳定区噪声被直接丢弃）就是 const 挡道的遗迹。

**相机参数（最终）**：ZED X Mini 4mm，HD1080 1920×1080，
fx=fy=1274px，cx=960/cy=540，HFOV 74°/VFOV 45°（Stereolabs 官方
标定表；实机以 SDK getCameraInformation() 实标为准）。
内参与深度模型更换后全几何矩阵需复测（交接文档 §八 第 3 项）。


## 十五、相机安装定案（宽轴沿机头）+ 航向伺服（2026-10-13 晚）

**安装定案（用户）**：实物安装为长视场边（宽轴 H74°/图像 u 轴）沿机头
方向。原仿真默认四元数 (0,√2/2,√2/2,0) 的宽轴沿机体右舷，与实物相反
（代码注释与投影数学双重核实：optical +X=body +Y、optical +Y=body +X）。
新四元数 **(0,1,0,0)**（绕机头轴 180°）：optical +X = body +X（机头/
宽轴），optical +Z = body −Z（朝上），右手系约束下 optical +Y = −body Y
（v 轴指向左舷）。同步点：camera_model.cpp 默认值、relative_estimator
参数默认值 + launch 显式钉住、netgun_mirror.py 正反映射（FOV 半角也对齐
0.6458/0.3927，镜像矩阵未重跑）。

**航向伺服（netgun_guidance_node）**：机头=宽轴对准目标航线。
yaw_sp 初始冻结为当前航向；估计有效且目标速度 >0.5 m/s 持续 0.3s
即起转（**hold 模式就转**，不等速度模式切换）；速率限幅 3 rad/s
（PX4 MC_YAWRATE_MAX 默认 200°/s 余量充足）；估计失效/目标静止
锁定当前值；circle/s_curve 就近短角差连续跟踪。参数：
yaw_servo_enabled / yaw_course_offset_rad（A/B 对比用）/ 
yaw_max_rate_rad_s / yaw_engage_speed_mps。

**v1 教训（先等速度模式再转 = 会丢目标）**：起步瞬态滞后 8-11° +
加速倾斜 ~14° 同向叠加 ≈22-25°，超过窄轴 ±22.5°——旋转完成前目标
已出视场（obs 全速率不可见、IMM 断粮、coast 速度爆炸至 30 m/s、
range 外推 800m）。提前+加速后解决。

**A/B 对比结果（offset 0=宽轴对准航线 vs π/2=窄轴对准航线）**：

## 十六、bearing-only 第①层：估计器纯方位量测（2026-10-14）

**背景（用户提级为交接清单第 3 项）**：实机 YOLO 检测到但自研估深无输出
（visible=true、depth_valid=false）时，旧逻辑整条拒收——连方向都不用，
滤波器断粮 coast 死锁。第①层让这种观测退化为纯方位量测。

**实现**：
- relative_estimator：入口门重排（深度字段条件仅在非 bearing-only 时
  施加）；像素→optical 单位视线→NED；名义距离=滤波器预测在视线上的
  投影（未初始化用 12m 先验）；协方差 optical 系 diag(横向σ=角σ×距离,
  距离σ=30m) 旋转到 NED——更新只修正横向、距离通道几乎不动（经典
  bearing-only 伪量测，滤波器连续运行不重启）
- 诊断加 bo= 计数；参数 bearing_only_update_enabled / nominal_range /
  range_sigma（launch 显式开启）
- 相机加 depth_valid_max_m（默认 -1=关闭，维持 2026-10-13 深度定案）：
  >此距离 depth_valid=false 而 visible/像素保留——复现实机检测在、
  估深无输出的情形，供测试
- 火控互锁自动成立：纯方位段位置方差超上限（25m²）→ est invalid →
  火控闭门；深度恢复+方差收缩后自动开门

**在线压力测试（depth_valid_max_m=8，8m 外只剩方位）**：

| 场景 | 结果 | bo 计数 | 对比全深度基线 |
|---|---|---|---|
| 追击 straight@5 | **PRIMARY 开火+命中 miss 0.85m** | 354 | miss 与基线一字不差 |
| 迎敌@3 | **PRIMARY 开火+命中 miss 0.80m** | 0（穿越段<8m） | ≈基线 0.73m |
| 追击 circle@3 | 未触发（单轮，基线 7/10 方差内） | 401 | 估计全程 valid=1/age=0.08 |

起步瞬态 8-15m 段全靠方位扛过，IMM 发散自恢复（reset 1-2 次）后仍
收敛到主支开火。**深度丢失段从"断粮死锁"变为"降级续跟"。**

**离线重放测试沉淀（测试装置经验，非实现问题）**：
- 正下方目标的方位对水平位置天然不可观（垂直视线方位不含 xy 信息）
——bag_v2a（坏轮，目标全程死点）上 bearing-only 的 xy 漂移 250m 是
不可观测性使然，z 误差 1.9m 正常。**验证 bearing-only 必须用离轴
几何**（迎敌穿越/圆周追踪），在线测试已覆盖
- 重放装置：/home/key/replay_bearing.py（bag obs+attitude→独立估计器，
  剥深度模式）；观测须重打戳到当前墙钟（姿态缓冲按接收时刻键控，
  bag 原戳差数小时会全部 attmiss）；误差统计须限观测窗（窗外 coast
  外推必然发散，均值会被尾巴主导）

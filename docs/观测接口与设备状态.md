# 观测接口与设备状态

当前感知入口只发布观测，不接入后续模块。结构化 ROS2 消息为 `/perception/observations`，JSON 对照为 `/perception/observations_json`。两者使用 SensorDataQoS；消费端应匹配通信配置并自行处理接收超时，不能要求每个采集帧均到达。

## 帧合同 v2

| 字段 | 含义 |
|---|---|
| `schema_version` | 当前为 2；新增消息字段后，订阅端必须重新构建 `zed_perception_interfaces` |
| `header.stamp` / JSON `stamp_ns` | 原图时间戳；不能替换成接收时刻来掩盖旧数据 |
| `header.frame_id` / JSON `frame_id` | `zed_left_camera_optical_frame`；X 右、Y 下、Z 前，位置单位米 |
| `boot_id`、`run_id`、`detector_generation` | 区分重启、采集运行和模型/开关切换；禁止混用旧状态 |
| `sequence` | 原始采集帧序号；推理优先最新图像，所以允许跳号 |
| `detector_enabled` | 与本帧实际识别状态一致；不再固定为 true |
| `processing_latency_s` | SDK grab 返回后，本节点获取帧至完成观测发布准备的处理耗时；不包含完整曝光/SDK grab 耗时，也不是网络端到端延迟 |
| `observations_fresh` | 识别有效且上述处理耗时小于 1 秒；过期或关闭时 targets 为空。新鲜不代表位置已测准 |

采集运行、识别关闭时持续发送空观测，`detector_enabled=false`、`observations_fresh=false`，避免接收端沿用暂停前的目标。相机停止或进程/网络中断时仍可能完全无消息，消费端必须保留独立超时判废。

## 目标合同

`depth`、`size_estimate`、`bearing_only` 分别表示通过当前深度质量检查的测量、依赖尺寸先验的估距、只有视线方向。`position_valid` 仅表示本帧能形成三维数值，不能单独作为可靠测距标记。

结构化消息与 JSON 均提供 `depth_measured_valid`、`size_estimate_calibrated`、`calibration_id`、`size_prior_m`。当前协方差未验证，`covariance_valid=false`；零协方差不能解读为无误差。失效目标中的零位置字段不能当作真实原点。

当前深度质量检查使用 0.3–10.5 m 范围，尺寸估距依赖目标有效尺寸与框占幅，目标姿态、框抖动会影响距离。目标 ID 来自图像关联，不保证遮挡后仍是同一 ID；连续三帧深度确认也不等同于连续位置滤波。

旧 `zed_track_filter_node.py` 接收单目标 `body_xyz`、`stamp_s`，当前输出多目标相机系坐标，两者不是直接兼容。未来需要明确目标选择、外参、时间同步、模式变化和失效处理；本次没有实现或启用旧链路适配。

## 只读验收

在板子上加载当前 ROS2 工作区环境，执行 `python3 ros2_ws/src/zed_tracking/tools/inspect_observations.py --seconds 20`。该工具只订阅感知话题，记录接收频率、序号间隙、状态合同错误、测距模式和处理耗时；不发布任何控制消息。结果没有真实目标时，只能证明帧接口和失效标志，不能证明位置精度或稳定性。

## 低频设备状态

监督服务约每 2 秒读取 Linux sysfs，并复用当前状态 RPC；相机停止时也可读取。采样缓存按 boot_id 与单调时间校验，重启、未来时间或损坏缓存会重新采样。电脑端把本次 RPC 完整耗时加入状态年龄，再与浏览器继续计时；连接异常或过期显示未知。重复操作请求保留原执行结果，但返回重新采样的当前状态，禁止把旧缓存当成新的时钟参考。

预览用帧采集单调时间、同一次 boot 的监督状态采样时间和电脑请求起点建立保守年龄上界，计入 TCP 缓冲等待。过期积压会断开并重连取最新画面；界面“画面时效”是这个上界，不是实测网络延迟。系统墙钟调整不会影响该判定。

温度来自热区；模组电压、电流来自 INA3221 的 `VDD_IN`，单位分别为 mV/mA，功耗为两者乘积换算成 W。它们不是整机电池电压或整机全部功耗。[NVIDIA 电源监测说明](https://docs.nvidia.com/jetson/archives/r36.4.3/DeveloperGuide/SD/PlatformPowerAndPerformance/JetsonOrinNanoSeriesJetsonOrinNxSeriesAndJetsonAgxOrinSeries.html)、[Linux hwmon 单位](https://docs.kernel.org/hwmon/sysfs-interface.html)。

网口 carrier 和标称速率只说明本地有线链路；控制往返包含 SSH 建连、命令执行和状态读取，不是 ping RTT。H100 无线 RSSI 接口尚未配置，界面显示“未接入”，不从网口速率、图像帧率或延迟推算信号百分比。

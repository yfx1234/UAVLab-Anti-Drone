# 任务流程框图：起飞 → 跟踪 → 瞄准 → 打击 → 标志

> 2026-10-15 按当前代码（AIM+SPIN+SETTLE、几何感知交接、秒级发散恢复）绘制。
> 参数为默认值，真源见 launch 与交接文档 §七。

## 一、主状态流

```
[解锁+offboard]                          auto: engage_delay 5s 后自动
      │                                  rc_gated: 等飞手拨杆（待机零 setpoint）
      ▼
┌──────────────┐   alt ≥ takeoff_height−0.3 (5.5m)
│   TAKEOFF    │──────────────────────────────┐  ▸ 进入 TRACK 同时发布 takeoff_ready(闩锁)
│  垂直爬升     │                              │    → 目标源起跑(+10s)、火控授权锚定(+12s)
└──────────────┘                              ▼
┌══════════════════════ TRACK 跟踪态（两个子形态）═══════════════════════┐
│                                                                      │
│  [HOLD 位置保持]                相对速度>0.8m/s 持续0.5s（入轨≥5s）     │
│   锚点=本机+低通估计  ─────────────────────────────►  [VELOCITY 速度+前馈]│
│   垂直间距锁 7.5m              （单向切换，种子=前馈速度）  P=2.0+FF+积分 │
│   方位伺服:瞄准线死区外偏置                                │           │
│                                                          │           │
│   yaw 伺服（hold 即转）: 目标速度>0.5m/s×0.3s → 机头对准航线 3rad/s     │
│                                                          │           │
│            est 失效 > 0.5s ──────────────────────────────┤           │
│                    ▼                                     ▼           │
│          ┌─[BEARING_HOLD 再截获]─┐   est 有效≥0.3s ∧ 速度/几何门        │
│          │ 沿最后方位逼近 3.5m/s  │ ───────────────────────────────────┘
│          │ yaw 扫描 ±25°/8s     │   来袭目标: |v|<1.0m/s 才交接（刹停）
│          │ 上限 20s             │   远离目标: 立即交接（种子=实际速度）
│          └──────────────────────┘   兜底: 确认后 2s 强制交接
│                                                                      │
│  AIM 进入: aim_enabled ∧ !BH ∧ est 有效持续≥2s ∧ 武器授权 ∧ 速度门    │
│                    ▼                                                 │
│          ┌─[AIM 主动瞄准]─────────────────────────────────┐           │
│          │ 速度种子=进入时刻实际速度（保持匹配）            │           │
│          │ a_ff = g·tan(θ)×1.15 朝 PIP(tof=|est|/55)      │           │
│          │ θ = atan2(|PIP_xy|,|est_z|)，钳 0.35rad(20°)   │           │
│          │ yaw 冻结；ob.velocity+acceleration 双通道      │           │
│          └───────┬────────────────────────────────────────┘           │
│                  │ 超时 0.8s 未开火 ∨ est 失效 → 回 TRACK（重计稳定2s）│
└══════════════════╪════════════════════════════════════════════════════┘
                   │ FIRE（火控门，见下）
                   ▼
┌──────────────┐  |v|<0.25m/s×0.3s ∨ 4s 超时
│   SETTLE     │────────────────────────┐   ▸ 开火动量在此段制动
│  悬停制动     │                        │     （v²/2a，yaw 冻结）
└──────────────┘                        ▼
┌──────────────┐  累计旋转 ≥ 2π
│    SPIN      │────────────────────┐   ▸ 1.8 rad/s 顺时针，位置/高度保持
│  原地旋转360° │                    │     （旋转段位移实测 ~0.09m）
└──────────────┘                    ▼
┌──────────────┐
│    DONE      │  原地保持至 offboard 退出（人工核验旋转后切出）
└──────────────┘

【任意时刻】!armed ∨ !offboard → rc_gated: 停发 setpoint、复位 WAITING（standby 日志）
【支撑层】IMM CV/CA/CT 连续估计；观测全拒>1.5s → 滤波器强制重置（秒单位，与帧率无关）
```

## 二、火控门（与制导形态无关，50Hz 持续评判）

```
est 有效 ∧ 武器授权 ∧ range∈[4.0, 9.8]m ∧ LOS率<0.5rad/s ∧ 单发未闩锁
   ├─ axis_err < 2°（瞬时）─────────► FIRE【主支】
   └─ axis_err < 4° 持续 0.2s ─────► FIRE【兜底】
axis_err 用实测姿态 vs 估计瞄准线独立计算——只认真实指向，不信任指令
武器授权（strike 发布 /tracking/weapon_authorization 10Hz）：
  armed ∧ offboard ∧ alt≥1.5m ∧ takeoff_ready ∧ +12s ∧ est 稳定≥2s
```

## 三、状态转换关键参数表

| 转换 | 关键条件 | 参数（默认） |
|---|---|---|
| WAITING→TAKEOFF | armed ∧ offboard | auto: engage_delay_s=5；rc_gated: 等飞手 |
| TAKEOFF→TRACK | 高度到位 | takeoff_height_m=5.8（差 0.3m 进入） |
| TRACK 发布 ready | 进 TRACK 即发（闩锁） | 目标起跑 +10s / 授权 +12s（同锚延时链） |
| HOLD→VELOCITY | 相对速度持续超阈 | track_engage_speed_mps=0.8×0.5s、入轨≥5s、单向 |
| TRACK→BEARING_HOLD | 估计失效 | estimate_timeout_s=0.5 |
| BH→TRACK（恢复） | 估计确认+交接门 | recover_confirm_s=0.3；recover_speed=1.0m/s（仅来袭）；recover_timeout_s=2 |
| 来袭/远离判据 | 相对速度·相对位置符号 | bh_closing（几何感知门） |
| TRACK→AIM | 稳定+授权+速度门 | aim_enter_delay_s=2.0；attack_enable_delay_s=12；stable_track_time_s=2.0；minimum_height_m=1.5 |
| AIM 指令钳制 | 倾角与补偿 | aim_max_tilt_rad=0.35；aim_tilt_compensation=1.15 |
| AIM→TRACK（回退） | 超时/估计失效 | aim_timeout_s=0.8（重计稳定时间） |
| 火控 FIRE | 五门联锁 | primary 2° / window 4°×0.2s / LOS 0.5rad/s / 距离 [4.0,9.8] / 单发闩锁 |
| FIRE→SETTLE | shot 事件 | spin_flag_enabled=true |
| SETTLE→SPIN | 停稳确认 | spin_settle_speed_mps=0.25×0.3s；spin_settle_timeout_s=4 |
| SPIN→DONE | 转满 | spin_rate_rad_s=1.8；spin_total_rad=2π |
| 估计器重置 | 无有效更新 | divergence_reset_period_s=1.5（断流不触发） |

## 四、时间链示例（pursuit 场景）

```
t0    TRACK 进入，发布 ready
t0+10 目标起跑（斜坡 2s 加速到设定速度）
t0+12 火控授权打开（就位锚+delay+稳定跟踪）
t0+14 前提满足 2s → AIM 进入（慢速档；快速档多在瞬态几何窗口提前开火）
+0.1~0.3s 2° 主支 FIRE → SETTLE（~3s 制动）→ SPIN（3.5s）→ DONE
```

# 实物调试指南（调试话题选择 + 失败归因手册）

> 2026-10-15 建立。配套改动：三节点调试话题 + `netgun_real.launch.py`
> （授权延时 2s + rc_gated + /fmu 实机命名空间）。

## 一、调试话题选择（为什么是这三个）

选择原则：**每个节点一条聚合话题**（String key=value 单行，2Hz），
而不是每个状态一个话题——外场 `ros2 topic echo` 一次看全、bag 录制
一条线、grep 直接可查；实现上零接口包改动（std_msgs/String）。
速率 2Hz：人眼可读、90s 架次 ~180 条、bag 占用可忽略。

| 话题 | 发布者 | 回答的问题 |
|---|---|---|
| `/debug/guidance_state` | 制导 | 飞机在干什么（phase/形态/AIM/SPIN）、授权收到没、站位对不对、发了什么指令 |
| `/debug/strike_state` | 火控 | 为什么（还）没开火——授权链逐项 + 五门各自通断 |
| `/debug/estimator_state` | 估计器 | 看没看见目标、滤波器健不健康、IMM 信哪个模型 |

链路归因顺序：estimator → strike → guidance（感知没数据则后两者
必然异常，从上游查起）。

## 二、字段字典

### /debug/guidance_state
```
phase=WAITING|TAKEOFF|TRACK|AIM|SETTLE|SPIN|DONE   主状态机
hold=1     TRACK 内位置保持形态（0=速度+前馈形态）
bh=1       BEARING_HOLD 再截获中（估计曾失效）
aim=1      AIM 瞄准中
auth=1     收到武器授权（strike 下发）
est=1      估计有效（valid+时效）
tspd=2.14  估计相对速度 m/s
stab=12.3  AIM 稳定计时（-1=未开始；≥aim_enter_delay 可进 AIM）
aim_t=0.31 AIM 已进行时长（-1=不在 AIM）
pos/vel    本机 NED 位置/水平速度
yaw=86.8   航向设定点 deg
tgt=...    站位保持目标（hold 形态=目标地面点；开火后=锚点）
spv/spa    最近下发的速度/加速度前馈指令（AIM 时 spa=倾角指令）
spin=0.00  SPIN 累计角 rad
srch=0      初始搜索自旋中（无目标时=1）
to=0/1     task origin 是否已锁定
```

### /debug/strike_state
```
est=1            估计有效（火控口径）
auth=1           授权通过（下面五项的与）
arm/ob/h=1       armed / offboard / 高度≥1.5m
rdy=4.9/12.0     就位后经过时间/延时阈值（实机阈值=2.0）
stb=12.8/2.0     连续有效跟踪时长/阈值
range=7.48[4.0,9.8]  距离与窗口
axis=0.48deg(p=2.0 w=4.0)  轴误差与两道门限
los=0.135/0.50   LOS 率与门限
gates r/p/w/l=1  距离/2°主支/4°兜底/LOS 各门通断
gates t=1        倾角门（枪管轴偏离竖直 ≤45°；自动开火另需 t=1）
shots=0          已开火数（单发闩锁）
fmode=auto_manual  开火模式（实机默认：自动单发+手动兜底；auto/manual）
fready=1         此刻按"发射网枪"会发射（手动兜底门全通）
tilt=3.2         枪管轴偏离竖直角度（°）
mblk=NOT_ARMED   手动兜底被拦首因：NONE/DISABLED/LATCHED/FCU_STALE/
                 NOT_ARMED/LOW_HEIGHT/TILT/NOT_AUTHORIZED
```
（I-3 起 `auth` 为对外发布的武器授权，不含倾角；自动开火 = auth ∧ t ∧ 五门。）

### /debug/estimator_state
```
init/valid     滤波器初始化/输出有效
age=0.03       距上次有效更新秒数（>max_data_age 即失效）
obs/inv/att    观测到达/预门无效/姿态 miss 计数
acc/bo/rst     接受/bearing-only/强制重置 计数
pos/vel        估计相对位置/速度（NED，目标-本机）
var=0.004      位置方差（超限→valid=0→闭门）
mp=0.49,...    IMM 模型概率（CV,CA,CT）
```

## 三、失败归因速查（症状 → 看哪个字段）

| 症状 | 首查字段 | 判读 |
|---|---|---|
| 全程不动、无输出 | estimator `obs` | obs 不涨=感知源没发数据（查感知节点） |
| obs 涨但 inv 同涨 | estimator `inv` | 预门无效：可见性/深度/像素字段坏（接口对齐问题） |
| obs/acc 涨但 valid=0 | `age`、`var` | 断流（感知闪断）或方差超限（深度质量差） |
| 跟着跟着丢了 | estimator `rst`、guidance `bh` | rst 涨=革新门死锁触发重置；bh=1=已进再截获 |
| 不进 AIM | guidance `stab`、`auth` | stab 涨不到 2s（估计闪断）或 auth=0（查 strike 侧） |
| auth=0 | strike `arm/ob/h/rdy/stb` | 哪项不满足一目了然（常见：rdy 未到延时、stb 被闪断清零） |
| 授权了但不开火 | strike `gates` | r=0 太远/太近；p/w=0 轴误差大；l=0 LOS 率超 |
| 授权且五门通但不开火 | strike `gates t`、`tilt` | t=0：机体倾角 >45°（倾角门） |
| 按钮无效 | strike `fready`、`mblk` | mblk 即首因：NOT_ARMED 未解锁、LOW_HEIGHT 高度不足或 z_valid=0、TILT 倾角大、FCU_STALE 飞控数据断、LATCHED 已发过、DISABLED 模式为 auto |
| guidance `fcu=0` | guidance `stms`、`lpms` | stms=-1：收不到 vehicle_status（status_topic/px4_msgs 不符）；lpms 正常但 fcu=0：本地位置无效（无 GPS） |
| 开火 miss 大 | strike `axis` 开火瞬间值 + estimator `var` | 边缘几何或估计误差大 |
| 旋转段飞走 | guidance `phase/spin/tgt` | SETTLE 未停稳（vel 大）或锚点异常 |
| 切出后还在动 | guidance `phase` | 应回 WAITING 并停发（首飞检查项） |

## 四、实物 launch 用法

```bash
ros2 launch netgun_intercept netgun_real.launch.py
# 授权延时改 0（取消）：
ros2 launch netgun_intercept netgun_real.launch.py attack_enable_delay_s:=0.0
```

- 实机默认 **2s**（就位信号后防抖）；仿真 launch 保持 12s 不变
  （与虚拟目标起跑对齐的矩阵口径）。
- PX4 话题走 `/fmu/...` 实机命名空间；感知输入等 ZED+DeepStream
  源发布 `/perception/depth/observation`（接口契约见
  anti_drone_interfaces/DepthObservation V1）。
- 开火（I-3）：默认 `fire_mode:=auto_manual`（自动单发 + 面板按钮兜底）；
  `fire_mode:=auto` 只自动、`fire_mode:=manual` 只按钮。实物击发：
  `trigger_command:="bash /path/pwm_fire.sh"`（异步执行，环境变量
  `NETGUN_SHOT_ID`/`NETGUN_SHOT_REASON`，契约见 netgun_intercept README）。
  开火事件仍发 `/tracking/virtual_shot_event`。
- 飞控为 PX4 v1.15.x：`status_topic` 默认 `/fmu/out/vehicle_status`
  （`_v1` 是 v1.16+ 才有的兼容话题，勿用）；板上 px4_msgs 必须是
  release/1.15 `a1045ec` 原版。
- 相机与枪口杠杆臂（2026-10-23 修订）：在面板「拦截任务 → 安装参数」以网枪顶面
  中心为基准填写（默认：相机顶面同高、轴线右侧 6 cm、右目朝机头；RTK 顶面下
  12.2 cm；飞控顶面下 18 cm），`run_interceptor_stack.sh start` 自动换算成
  `camera_translation_body_*`、`camera_q_body_to_optical_*`、`muzzle_offset_body_*`
  launch 参数；launch 默认 (-0.025, 0.06, -0.16) / 枪口 (0, 0, -0.18) 与该默认值
  一致。枪轴与光轴平行，`boresight_*` 固定 0。命令行显式参数仍可覆盖。换算与
  飞控/RTK 标定见 `docs/安装参数与标定_2026-10-22.md`。
- 节点选择：估计器/制导/火控三个核心节点；裁判与真值链为仿真
  专有不入实机；感知源与 GPIO 为待接入件。

## 五、外场采证配方

```bash
# 全套调试话题 + 关键 PX4 状态一条录（掉线/坠机后复盘）
ros2 bag record -o field_run_N \
  /debug/guidance_state /debug/strike_state /debug/estimator_state \
  /fmu/out/vehicle_local_position /fmu/out/vehicle_attitude \
  /fmu/out/vehicle_status /tracking/relative/estimate \
  /tracking/weapon_authorization /tracking/virtual_shot_event
```

注意（坑表）：录前若 DDS 发现异常（topic echo 探不到），先
`ros2 daemon stop && ros2 daemon start`；bag 目录已存在会秒退。

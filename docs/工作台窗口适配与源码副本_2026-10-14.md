# 工作台窗口适配与源码副本（2026-10-14）

本轮按用户追加反馈调整素材库与常驻文案，延续无外围描边、胶囊按钮、大圆角白色表面和柔和阴影。只部署电脑端 HTML，不启动相机、不改变采集或观测合同。

## 界面变化

- 下载栏缩窄，图标与两行文字整体居中，按钮高度收紧；保留 RGB、深度和 SVO 三种实际下载操作。
- 桌面板上场次栏使用与控制栏一致的 sticky 定位和窗口内滚动；窄屏恢复自然堆叠。
- 删除常驻 YOLO 输入限制提示、预览解释和重复的整场下载说明；编码选择直接显示 `LOSSLESS`、`H264_LOSSLESS`。实际禁用与录像锁定逻辑继续由状态控制。
- 字体基于已安装 Codex 桌面资源中核实的默认 `-apple-system, BlinkMacSystemFont, Segoe UI, sans-serif` 组合，补充中文回退 `Noto Sans SC, PingFang SC, Hiragino Sans GB`。当前 Windows 已安装 Noto Sans SC；没有安装 SF Pro 或苹方，也不复制它们或 Codex 专有字体文件。
- 本机视频根据窗口可用高度等比缩小整个卡片。播放器仍保持 16:9，画面、原生播放控件和实际视频信息一起显示；没有裁切、拉伸或降低视频分辨率。

## 验证

真实浏览器以用户截图的 1784×946、较矮的 1280×720、390px 手机宽度和 547px 应用侧栏检查。1784×946 的视频为 933×525，底边 751px，设备状态栏起于 859px；1280×720 的视频为 532×299，底边 525px，状态栏起于 633px。两者原始媒体都是 1920×1080。手机宽度没有页面水平溢出。

场次栏内部可滚动；1280×720 中页面滚动约 23px 时场次顶部仍处于约 126px，内部再滚动 20px 不移动卡片。sticky 受所在工作区末端约束，防止覆盖后续内容。较窄屏幕不强制固定场次栏。

功能回归 135 项：134 通过，1 项因 Windows 符号链接条件跳过。测试覆盖既有备注、场次、下载续传、时序、前端状态与传输新鲜度；本轮没有新增硬件或实物精度验收。设计检测中的 11px 提示为路径、单位等辅助文字；主操作与标题采用 13–22px。设计文档同步本轮字体、下载栏与窗口适配规则。

## Gitee 源码副本范围

用户指定目标仓库 `https://gitee.com/buaalab/anti-drone-interceptor`。新增独立的 `perception-workbench` 目录，保留目标仓库原说明文件，并添加入口链接。副本从确定的 GitHub 源码提交导出，`SOURCE_MANIFEST.json` 记录源提交和逐文件 SHA256。

发布范围为感知/相机/录像/观测接口、电脑面板、回归测试、环境参考和维护文档。录像、缓存、凭据、模型权重和 TensorRT 引擎不进入副本；模型需单独提供并在目标 Jetson 上构建。副本默认关闭历史飞控工具，不接入下一模块。模块 README 说明启动、构建、模型缺失和验收边界；实际推送结果由发布时远端提交核对确认。

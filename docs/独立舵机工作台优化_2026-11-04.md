# 独立舵机工作台优化记录

日期：2026-11-04。范围：独立舵机台架的 Operate 操作面扩展。

本轮沿用 UAVLab 的浅灰工具底、白色内容面、石墨主操作、系统 UI 字体、胶囊按钮与分尺度圆角。既有 `PRODUCT.md`、`DESIGN.md` 和 `.impeccable/design.json` 保持原样；本页的局部操作布局和数值尺度不成为整个感知/采集平台的新规范。

## 操作面与行为

- 位置控制提供换算角度、目标 PWM、滑块、±5°与回中；“拖动即发送”是显式勾选项。角度根据飞控脉宽范围和可编辑角度行程换算，不是舵机角度传感结果。
- 动作方式可选择短时测试或保持当前位置。短时可编辑 0.2–30 秒；保持依赖发起页面续期。页面退出、会话失效或遥测过期会结束测试；每条底层飞控测试指令仍独立在至多 1 秒后失效。
- 动作序列可编辑目标角度、转动用时与停留时间，支持添加、删除、上移重排、JSON 导入/导出、1–20 次重复和结束后回中或保持末点。展开重复后的序列限制为 1–200 点。
- “停止”位于 sticky 页头，滚动时仍可见，Esc 调用同一停止操作。动作按钮依赖连接、配置已核对、遥测可用和飞控未解锁；页面不发送解锁或写飞控参数操作。
- “短时后回中”和序列结束“回到中位”实际释放测试覆盖，恢复飞控已配置的未解锁输出。本次验证中该输出为 1500 µs；不能据此断言所有安装均为脉宽上下限的中点。
- 页面新开或刷新不继承上一页面的动作租约；恢复连接状态不等于恢复旧页面的保持动作。

## 局部组件与布局

桌面左列为位置控制和动作序列，右列为设备连接、输出反馈与六条操作记录。最大容器宽度为 1424px，宽屏为 1460px；设备列按断点使用 328/348/300px。860px 以下设备区域移到控制区后方，560px 以下自然单列；只有序列表在自身容器内横向滚动。

位置读数承担台架操作的主要层级：换算角度为 54/48/44px，目标 PWM 为 22/20px，主反馈 PWM 为 29px。860px 以下在应用按钮下方补充 18px 的实时 PWM 与新鲜度，避免操作者必须滚动到下方设备区才能核对输出。该尺度只用于这个操作面；全局指标仍沿用既有 18px 角色。

主操作按钮采用 40px 最小高度，小按钮 34px；行为单选组采用 12px 外圆角和 10px 选中段。白色表面桌面 24px、手机 18px，采用本页轻阴影。输出图使用灰色虚线目标预设、绿色实线飞控反馈与动态高低刻度；目标预设和反馈来源明确区分。没有数据时保留空态，不补造曲线。图表保留的历史样本不等于当前反馈仍有效。

具体局部尺寸、交互和继承边界见 [servo-bench surface brief](../.impeccable/surface-briefs/servo-bench.md)。

## 已知差异与后续边界

既有实现的正常状态绿字、浅绿动作状态底与全局“中性文字加绿点”规则有差异；焦点颜色/偏移、禁用色和系统字体回退栈也未逐项复用全局定义。本轮只记录这些已存在差异，没有修复全局文件、覆盖 incumbent 规范或宣称完全一致。局部数字尺度与操作布局则已明确登记在 surface brief。

剩余验证为 JSON 文件导入/落盘导出全过程，以及按实际舵机规格开展的行程和实体角度测量。当前只确认指定小幅台架 PWM 行为，不把飞控反馈等同于舵机实体位置，也不延伸为其他相机、感知或飞行功能验收。

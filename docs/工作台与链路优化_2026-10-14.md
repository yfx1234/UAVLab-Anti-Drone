# 工作台与链路优化 · 2026-10-14

本轮已部署到现用板子与电脑面板。按用户要求采用接近成熟 Codex／Apple 软件的中性界面：统一按钮、字体层级、模块边界与工作区导航；保持实时画面、录像与素材管理的原有操作流程。

## 实际改动

| 环节 | 复核与处理 |
|---|---|
| 采集／深度／推理 | 保留唯一相机拥有者、最新一帧队列、YOLO独立开关与非阻塞TensorRT流；未改变默认1080p15、功率或深度参数。过期推理结果和失效代次不发布目标。 |
| 观测输出 | ROS／JSON帧合同v2新增boot身份、新鲜标志与处理耗时；目标同步尺寸估计是否标定和先验。YOLO暂停期间持续发送空观测，避免接收端沿用旧目标。 |
| 图传预览 | 原先未计入TCP队列等待；现在使用同boot单调时间参考计算保守年龄上界，积压过期重连。画面显示和目标判废使用一致的年龄，避免状态刷新与画面刷新交替显示不同读数。 |
| 控制与设备状态 | 约两秒采样、复用现有状态RPC；电压／功耗明确是VDD_IN模组供电。RPC传输时间计入状态年龄；重复操作返回当前状态而不重做操作。无线RSSI没有数据源，显示“未接入”。 |
| 录像／导出 | 本轮未改原始SVO、分段合并、深度展示与备注存储；保留现有完整场次下载。未新增测试录像或删除外场素材。 |
| 下载恢复 | 已复现损坏的完整.part造成无限校验失败；失败后仅重置本次临时文件，保留已发布副本。正常中断／取消仍保留续传。 |
| 界面 | 中性浅灰、石墨主操作、系统字体、稳定目标表、可折叠设备状态。修复素材日期重复、输入提示对比度与控制抽屉箭头。默认本机素材优先选择最近完整RGB视频。 |

## 验证与边界

- 本机135项单元／行为测试：134通过、1项Windows符号链接条件跳过。板上原生构建与7项CTest通过。部署源文件比对覆盖65项板上源码及全部面板源码，差异为0。
- 首轮YOLO开启15.070秒收到226帧，14.997Hz；暂停15.051秒收到226帧，15.016Hz。序号间隙和合同错误均为0。开启处理耗时最大82.6ms，暂停最大9.45ms。
- 后续包含开启切换的15秒接收窗口为197帧、13.120Hz，仍无连续序号间隙／合同错误；该窗口不是稳定吞吐保证。同期节点最后一秒采集／推理约15Hz；不能据此认定所有切换后的15秒窗口均达15Hz。后续暂停窗口226帧、15.026Hz。
- 硬件原始读取中位数约14.7–16.1ms，缓存加监督状态读取约0.57–0.85ms。只读取CPU侧文件，未增加GPU计算；未做长时间资源占用A/B试验，不能宣称零开销。
- 现场验证使用室内静态画面，识别存在未标定尺寸估距输出；本轮验证接口与失效处理，不证明真实四旋翼精度、ID连续性或移动相机下的位置稳定。没有接入下一模块。
- 桌面实际1280px布局、设备状态键盘开合、完整本机1920×1080／220.333秒视频元信息已检查。初轮窄屏检查有效，最终复验时浏览器viewport工具不再按请求改变宽度，最终窄屏截图无效。Impeccable最终审查结论为`recapture`；不宣称完整响应式视觉验收通过。已发现的四项修正落实于源码，最终完整视觉评分仍待有效窄屏截图。
- 本轮未创建SVO／MP4场次；测试完恢复相机停止，面板保持连接，停止采集后设备状态仍可读。

接口字段、坐标意义与后续消费端的重建要求见[观测接口与设备状态](观测接口与设备状态.md)。此前30fps限制、原图画质、两次外场完整下载和1080p输入比较沿用[NX性能与外场复核](NX性能与外场复核_2026-10-14.md)的已验证结论，不能由本轮15fps短测替代。

# GLAD 模型接入与素材库检测预览（2026-10-16）

把 GLAD（WindyLab/Global-Local-MAV-Detection，西湖大学，T-ITS 2024）的
**全局外观分支**部署为面板可选检测模型，并新增"检测预览"功能：对素材库
场次视频跑任意已注册模型并生成画框标注视频，用于实飞前对比模型效果。

## 结论速览

- GLAD 全局分支 = 单类（MAV）YOLOv5s v6.0，7.0M 参数；导出为端到端 NMS
  ONNX（[1,300,6]）后在 NX 构建两档 FP16 引擎，全部通过平台合同自检，
  **可在面板 YOLO 输入下拉中实时切换**（实测 15Hz 正常运行）。
- 已知定位（重要期望管理）：既有离线筛查 GLAD 63/67 vs 现模型 65/67
  （1280 档，`docs/experiments/2026-10-16-large-dataset-screening.json`）；
  且 GLAD 研究口径阈值 0.25，平台统一 0.55——短场次实测 GLAD 明显更保守
  （114 帧仅 1 帧检出，现模型 114/114）。它是"换训练数据（ARD-MAV，主打
  远小目标）的备选"，不是精度升级。
- License：仓库无 LICENSE 文件（仅 MIT 徽章，GitHub license=null）——
  实验室内使用；对外发布前需联系作者确认。权重/引擎不入 git。

## 导出方法（可复现）

PC（detection_research_20261016 工作区 `.venv`，torch 2.13）：
`export_glad_e2e.py`——vendored yolov5 v7.0 weights_only 加载（ultralytics
包拒绝 v6.0 仓库权重，走显式类加载），包装端到端头（Detect 输出
cx,cy,w,h → xyxy → conf 0.25 过滤 → torchvision NMS(0.45) → topk300 →
零填充 [1,300,6]），`torch.onnx.export(dynamo=False, opset 12)`。
**数值验证：与 AutoShape 参照逐帧框 IoU=1.0。**
关键坑：Detect 推理输出是 cx,cy,w,h 而非 xyxy，不转换会让 NMS 失效。

板上：`trtexec --onnx=… --saveEngine=… --fp16 --builderOptimizationLevel=3`
（构建需停相机）；`build_model_manifest.py` 生成边车（再手工补
source_pt/onnx_sha256 与 class_names，工具启发式只认 exp 命名）；
`zed_perception_standalone --check-model` 合同校验。

## 面板改动

- `modelInputLabel`：白名单加 `[1,3,384,640]`；按模型名区分
  "GLAD 通用 MAV · …" 与 "原输入/1080p"。
- 素材库新增"检测预览（试模型）"：选场次+模型 → `annotate_session`
  动作（板上 onnxruntime CUDA 跑整场 RGB、同平台预处理与 0.55 阈值、
  画框）→ SFTP 取回存 `exports/annotated/*.view.mp4` → 本机视频列表可播。
- `board_client.fetch_file`（paramiko SFTP，常量路径）。
- 首次使用某场次前需先下载过一次整场 RGB（本机场次目录已存在）；
  若板上未导出 MP4，动作会自动走 export（相机须停止）。

## 实测记录（2026-10-16）

- 运行时切换：GLAD 384 引擎 set_detector → detector_state=2、
  inference 15Hz、nchw [1,3,384,640]；切回默认 817e17 正常。
- 标注对比（session_f9100c36，114 帧，阈值 0.55）：
  现模型 114/114 帧、60.4ms/帧；GLAD-1280 0/114、67.2ms/帧；
  GLAD-384 1/114、39.2ms/帧（板上 ort CUDA EP，fp32）。
- 面板全流程：下载 RGB → 生成标注 → 媒体列表出现并可 HTTP 播放 ✓。

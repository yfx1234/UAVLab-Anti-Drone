# ZED 感知与采集：简单使用版

当前用 Orin Nano 8GB，换 NX 16GB 后再做迁移和30fps验收。

1. 相机、板子供电，接通图传。运行同目录“启动ZED感知与采集平台.ps1”，打开 http://127.0.0.1:8767/，点击“连接板子”。
2. 采训练素材选“纯采集：RGB，无深度”，帧率先用15fps。观察识别和定位选“感知：YOLO + 深度与估距”。切模式先停止相机。
3. 点“启动相机”，可填写采集备注/背景/光照，点“开始原始素材录像”。双目原片保存在板子；图传断开、电脑关闭后仍继续录像。
4. RGB / YOLO只切换本机显示。希望保存识别效果时，另开“本机预览录像”，可选带框或无框；它与板上原片录像独立。
5. 结束先“停止原始素材录像”，等待收尾。首次生成下载视频时，再“停止并释放相机”。关闭浏览器不会自动停止板上录像。
6. “视频下载与本机素材”中刷新、选择场次（按实际录制时间最新在前，手动采集默认用北京时间命名），然后按需要下载：
   - **下载原始 RGB 视频**：无框、单目1920×1080 MP4，方便电脑播放和抽帧。MP4经过压缩；双目无损原片见SVO。
   - **下载深度展示视频**：默认不生成，点击后才由板子离线计算。是彩色展示视频，不是逐像素米制深度数据。
   - **下载原始双目素材（SVO）**：保留无损双目图像，文件较大；后续重算深度用它。
7. 已生成的视频可在采集中下载；首次生成需停止相机。采集中下载限制256KiB/s，停止相机后自动取消限速。本次图传实际测到约0.67MiB/s；“高速”表示取消软件限速，不承诺链路速度。
8. 点击“修改名称”可改名称，已下载的电脑素材文件夹及关联预览录像也会同步改名，顺序仍由录制时间决定。若电脑视频被占用，关闭播放后可用相同名称重试。“删除整个场次”确认后永久删除板上该场次全部文件，电脑已下载副本保留；录制、收尾、下载或转换中的场次不能删除。
9. 下载后在本机视频列表播放，点击“打开所在文件夹”定位文件；点“本机抽训练图片”默认2fps，PNG保存在电脑。图片需用标注软件标注后训练。取消下载保留.part，再点同类下载可续传并校验。

标定、模型测试、日志和复盘由SSH完成，页面只留日常操作。深度转换首次可能耗时；转换期间点取消，要等板上转换结束才生效，转换结果会保留。

## 分辨率与帧率

相机采集和RGB下载都是1920×1080；当前旧YOLO模型输入是1280×736，两个尺寸独立。要改YOLO到1920，需要生成并验证新引擎，不能只改页面数值。常见stride32模型会把1080补到1088；1920×1088的输入像素约是现模型的2.22倍，实际推理耗时和内存必须另测。

当前默认15fps。30fps纯RGB+无损SVO短测得到595个独立图像、32.632秒，平均18.20fps，尚未达标。MP4为保持时长会重复前帧，标称30fps不代表真实采到30个新图像。NX替换后再验收真实30fps及YOLO并行表现。

## 感知结果

有效深度：通过质量判断后，输出目标表面的相机坐标。尺寸估计：深度不可靠时，按约30cm外廓和检测框估距，属于近似值。仅方向：框太小或触边等情况下，不输出有效位置。

相机坐标X向右、Y向下、Z向前，单位米。真实四旋翼识别、位置误差和尺寸标定按你的安排后续测试；目前室内背景仍可能误检。约30cm需明确是否包含桨叶、测的是哪个外廓。

## 深度视频修复

旧导出漏设米单位，0.3–10.5被当成毫米，导致全黑。新版已显式用米，并使用ZED SDK原生VIEW::DEPTH彩色显示；旧深度缓存自动失效，重新点击深度下载会重算。完全没有有效深度的视频不会作为成功结果发布。黑色区域仍可能表示真实无效/超范围像素。

# ZED 感知与采集：简单使用版

当前为 Orin NX 16GB，使用最高档 MAXN_SUPER。默认仍为1920×1080/15fps原图无损；30fps压缩RGB与原图无损的实测边界见 [结项复核](NX结项复核_2026-10-14.md)。

1. 相机、板子供电，接通图传。运行同目录“启动ZED感知与采集平台.ps1”，打开 http://127.0.0.1:8767/，点击“连接板子”。
2. 默认1920×1080/15fps，启动时只显示RGB，不计算深度。需要检测和定位时点“开启通用检测”或“开启 YOLO”，任一种开启都会启用深度；两种都暂停后才关闭深度计算。无需选择运行模式。分辨率与帧率只能在相机停止后修改。
3. 点“启动相机”，可填写采集备注/背景/光照，点“开始板上录像”。双目原片保存在板子；图传断开、电脑关闭后仍继续录像。
4. RGB / 检测叠加只切换本机显示；画面右上角可全屏监看。电脑预览录像入口已移除，旧电脑视频继续能播放；板上原片录像保留。录像中可以开关已绑定模型的YOLO，原始SVO连续录制。
5. 结束先“停止板上录像”，等待收尾。首次生成下载视频时，再“停止相机”。关闭浏览器不会自动停止板上录像。
6. 切换到“素材库”，刷新、选择场次（按实际录制时间最新在前，手动采集默认用北京时间命名），然后按需要下载：
   - **下载原始 RGB 视频**：无框、单目1920×1080 MP4，方便电脑播放和抽帧。MP4经过压缩；像素一致的双目训练原片需选择“训练采集 · 原图无损”并保留SVO。
   - **下载深度展示视频**：默认不生成，点击后才由板子离线计算。是彩色展示视频，不是逐像素米制深度数据。
   - **下载原始双目素材（SVO）**：保留场次双目图像，文件较大；后续重算深度用它。训练采集为像素一致的LOSSLESS，高速录像采用压缩格式。
7. 已生成的视频可在采集中下载；首次生成需停止相机。运行任一种检测或录像时保守限速256KiB/s；两种检测/深度均暂停、只采RGB且状态新鲜、帧率/内存/温度正常时Nano加速至768KiB/s；已适配NX16且可用内存≥6GiB、帧率≥请求值90%时可1MiB/s，状态未知或异常时回到保守档；停止相机后取消软件限速。先前停机短测约0.67MiB/s，本轮1MiB只读短测约1.02MiB/s，不能当持续速度保证；“高速”表示取消软件限速，不承诺链路速度。
8. 点击“修改名称”可改名称，已下载的电脑素材文件夹及关联预览录像也会同步改名，顺序仍由录制时间决定。若电脑视频被占用，关闭播放后可用相同名称重试。“删除场次”确认后永久删除板上该场次全部文件，电脑已下载副本保留；录制、收尾、下载或转换中的场次不能删除。
9. 下载后在素材库的视频列表播放；多段录像会自动生成并优先打开“整场视频”，原来的约一分钟分段保留。整场视频按分段数字顺序重封装，保留全部已有画面；切段期间未采集的间隙不能恢复，不用补帧冒充采集。点击“打开所在文件夹”定位文件。抽帧与标注使用电脑专用工具或脚本，页面已移除抽训练图片入口。取消下载保留.part，再点同类下载可续传并校验。

“实时监看”和“素材库”只切换界面，不启停相机或录像。返回实时监看会暂停本机视频回放。目标列表固定高度，内容多时在列表内滚动；操作提示浮在页面上，不推动布局。标定、模型测试、日志和复盘由SSH完成，说明文字保留在本指南。深度转换首次可能耗时；转换期间点取消，要等板上转换结束才生效，转换结果会保留。

## 分辨率与帧率

相机默认采集和RGB下载是1920×1080；选择1920×1200或960×600后，原始RGB视频保留所选的真实尺寸，不会上采样冒充1920。当前旧YOLO模型输入是1280×736，两个尺寸独立。要改YOLO到1920，需要生成并验证新引擎，不能只改页面数值。常见stride32模型会把1080补到1088；1920×1088的输入像素约是现模型的2.22倍，实际推理耗时和内存必须另测。

当前NX16使用MAXN_SUPER最高档，默认1080p15。训练采集选“原图无损”；若优先30fps、接受少量颜色变化，可选择“高速录像 · 压缩”。10月14日同一最高档短测：原图无损RGB约24.23Hz，原图无损＋旧YOLO/深度约21.85Hz；旧YOLO/深度不录像与硬件压缩录像均30Hz。高帧率必须区分采集、推理及全程含切段间隙的平均值；MP4标称30fps不是实际独立图像30Hz。最新实测与边界见 [性能与外场复核](NX性能与外场复核_2026-10-14.md)。

## 感知结果

有效深度：通过质量判断后，输出目标表面的相机坐标。尺寸估计：深度不可靠时，按约30cm外廓和检测框估距，属于近似值。仅方向：框太小或触边等情况下，不输出有效位置。

相机坐标X向右、Y向下、Z向前，单位米。真实四旋翼识别、位置误差和尺寸标定按你的安排后续测试；目前室内背景仍可能误检。约30cm需明确是否包含桨叶、测的是哪个外廓。

## 深度视频修复

旧导出漏设米单位，0.3–10.5被当成毫米，导致全黑。新版已显式用米，并使用ZED SDK原生VIEW::DEPTH彩色显示；旧深度缓存自动失效，重新点击深度下载会重算。完全没有有效深度的视频不会作为成功结果发布。黑色区域仍可能表示真实无效/超范围像素。

Codex_柜子深度展示参考（15fps）来自你的柜子录制，保留作同取景对照；Codex_采集帧率验证（30fps设置）保留用于复盘当前 Nano 的真实18.2Hz；Codex_北京时间与命名验证（短片）用于时间链路复查。旧手动素材、异常和重复测试场次已按本次授权清理。以后你手动采集仍默认按北京时间命名。

## 下载等待分成几个阶段

页面分别显示视频生成、传输、校验与本机准备。第一次从SVO生成RGB/深度视频仍在板上计算，需要释放相机；下载已存在的视频不需要重算。传输复用已有新鲜状态，减少SSH等待；最后校验完整SHA256，取消保留续传文件。本机只对浏览器不能直接播放的编码进行必要转换，已兼容的视频直接重封装；分辨率、帧率与时长保持。

图传、素材体积和板上首次转换仍可能占主要时间。双目SVO特别大，日常查看优先下载RGB视频。全速下载要求停止相机，不只是停止录像或暂停YOLO。新加速档在观测到最新状态后按数据块降档，不能承诺设备状态变化到降档小于一秒；断链/状态过期使用保守档。


## 启动和换场地

本机服务运行时直接打开网页，不需要重复运行命令；电脑重启或服务关闭后，运行启动脚本一次。旧“启动Jetson诊断面板.ps1”和本目录“启动ZED感知与采集平台.ps1”启动的是同一个8767服务，都先检查是否已运行。

同一台电脑、同一套图传、同样固定IP可搬到其他环境，链路不使用场地Wi-Fi或互联网。本机以太网为192.168.50.101/24，板端192.168.50.100；页面无CDN或在线字体，YOLO引擎与ZED模型资源已安装。无需修改美国时区，场次依旧北京时间。无线遮挡/干扰会影响链路，新环境识别和深度质量需要实测；完全断电RTC保时仍待验证。

## 通用检测

通用检测可独立运行，也能同时开启YOLO。黄色G编号是未知目标候选，绿色Y编号是YOLO，重合显示“双源”；标准/高/低灵敏度可切换。通用评分表示对比度，不是四旋翼概率。超过10m仍可输出方位与按约30cm尺寸估计的Z和相机XYZ；触边或框太小仅给方向。实物精度、天空误检和移动相机表现尚待测试。操作见 [通用检测简单版](通用检测_简单使用版.md)，现场测试见 [测试步骤](generic-sky-field-test.md)。

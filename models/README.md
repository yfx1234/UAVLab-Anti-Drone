# 模型来源

platform_exp_20260909 为板上现用模型：exp.pt 为训练权重，exp.onnx 为可供NX重建的导出图。两者已与板上SHA256逐字节核对；model-index.json记录哈希。

exp_opt3.manifest.json保留历史Nano引擎合同与来源。当前NX默认为exp_nx16_fp16.engine、1280×736输入；引擎本体留在板上，不上传为可移植模型。

platform_exp_1080_20261014/exp.onnx由同一份exp.pt重新导出，输入为1920×1088：1080p原图上下各补4像素，不缩小。输出仍为[1,300,6]，drone类别、RGB/0–1/114补边合同保留。随附清单登记NX实机FP16引擎及源文件哈希；未改动训练权重、旧ONNX或默认引擎。候选帧率和散热边界见docs/NX性能与外场复核_2026-10-14.md；更高输入分辨率的实物识别精度仍待验证。

当前识别类别为drone，目标约30cm是估距先验。来源哈希不等于模型精度或ONNX与引擎数值等价验收。模型已有源工程记录，仓库不新增模型再分发许可。
